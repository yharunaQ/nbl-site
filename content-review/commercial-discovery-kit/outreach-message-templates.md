# Outreach Message Templates

内部 draft / discovery use only

## Template A: Employer-facing Intermediary

NBL は、障害や病気の有無にかかわらず参加できる社会の受け皿を、AI-native な operating layer として設計している。
いま、`employer-facing intermediary` と一緒に、issue structuring、workflow mapping、private knowledge layer、boundary design をどう pilot 化できるかを検討している。
これは人の相談窓口の外注ではなく、repeated use に耐える operating layer の導入単位を試す conversation。
もし関心があれば、1ページの package brief を共有したうえで、fit evaluation の短い conversation をお願いしたい。

## Template B: Design-forward Employer

NBL は、AI を人減らしではなく work redesign と participation design のために使う operating layer を設計している。
いま、1 本の workflow lane に絞って `NBL OS Pilot` を試せる employer を探している。
これは個別相談の外注ではなく、issue structuring、workflow mapping、private workspace、boundary design を導入する pilot。
もし方向性が近ければ、1ページの package brief を前提に、fit evaluation の conversation をお願いしたい。

## Template C: Research / Policy Lighthouse

NBL は、AI-native social OS の事業構造を、障害・病気の有無にかかわらない participation design へつなげようとしている。
いま、commercial fit だけでなく legitimacy と translation を補える lighthouse partner と conversation を持ちたい。
もし関心があれば、package brief と boundary note を共有したうえで、短い discovery conversation をお願いしたい。
