# Discovery Call Guide

内部 draft / discovery use only

## Call Goal

受注を急がず、`fit evaluation` を行う。

## Ask In This Order

1. いま繰り返し起きている friction は何か
2. その friction を持ち帰る owner は誰か
3. まず 1 本に絞る workflow lane は何か
4. repeated use はどこで起きそうか
5. human review boundary はどこに置けそうか
6. 何が package fit を壊しそうか

## Scorecard Fields

- repeated use potential
- named internal owner
- workflow redesign appetite
- boundary readiness
- operational context access
- private workspace readiness
- budget tolerance
- low automation pressure

## Falsification Trigger

- labor outsourcing expectation が強い
- unlimited support expectation が消えない
- final employment judgment support を求められる
