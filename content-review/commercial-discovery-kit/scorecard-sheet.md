# Scorecard Sheet

内部 draft / discovery use only

## Scorecard

1. repeated use potential
2. named internal owner
3. workflow redesign appetite
4. boundary readiness
5. operational context access
6. private workspace readiness
7. budget tolerance for startup + recurring
8. low automation pressure

## Rating

- 1 = weak
- 2 = partial
- 3 = strong

## Decision Rule

- target A と B は合計点だけでなく `boundary readiness` と `low automation pressure` を必須確認にする
- target C は revenue fit より legitimacy / learning fit を重く見る
