# Boundary One-Pager

内部 draft / discovery use only

## Principle

high-risk 領域は `AI-supported, human-decided` を原則にする。

## AI-Supported Zone

- issue structuring
- workflow mapping
- documentation draft
- resource suggestion
- missing-context question generation
- boundary note generation

## Must Escalate

- final employment decisions
- medical or diagnostic interpretation
- crisis / safety
- abuse / violence
- major missing context cases
- certainty claims under partial evidence

## Required Context Before Strong Guidance

- person
- job
- environment
- support
- time
- institution
- evidence

## Minimum Safe Message

`この pilot は、高リスク判断をAIだけで確定するためのものではない。`
