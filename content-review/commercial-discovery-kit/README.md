# Commercial Discovery Kit Review

更新日: 2026-03-16

## Purpose

commercial package の判断を、実際に discovery conversation で使える説明資材へ落とす。

## Review Questions

- package brief は operating layer を短く正しく伝えられているか
- exclusions list は unsafe fit を早く落とせるか
- boundary one-pager は high-risk escalation を誤解なく示せているか
- discovery call guide は scorecard 回収に十分か
