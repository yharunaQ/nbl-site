# Candidate Intake Checklist

内部 draft / discovery use only

## Before Adding A Candidate

- slot は A1 / A2 / B1 / C1 のどれか
- target condition に最低限合っている
- source / connection path が明記できる
- named owner の仮説がある
- red flag を 1 つ以上確認済み

## Before Scheduling A Call

- outreach note を送った
- package brief を送れる状態
- exclusions list を共有できる
- boundary one-pager を共有できる

## After The Call

- scorecard を 8 項目で埋める
- stop rule に触れていないか確認する
- next touch を決める
