# Shortlisting Rubric

内部 draft / discovery use only

## Knockout Conditions

- labor outsourcing expectation が強い
- final employment judgment support を期待している
- diagnosis-only framing が強い
- named owner の仮説が立たない
- repeated use が見えない

## Core Fit

- 3 = strong
- 2 = partial
- 1 = weak

## Slot Check

### A1 / A2

- employer network
- contextual review / escalation willingness
- translation value

### B1

- workflow redesign appetite
- sponsor clarity
- 1 lane focus

### C1

- legitimacy / translation value
- learning value
- commercial lead でない理解
