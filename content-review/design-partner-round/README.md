# Design Partner Round Review

更新日: 2026-03-16

## Purpose

最初の design partner を `employer` に置くか `intermediary` に置くかを review する。

## Review Questions

- first design partner は recurring model と learning loop に合っているか
- partner edge と human review boundary を安全に置けるか
- employer direct が custom consulting trap に戻っていないか
- outreach と scorecard が次の 2 週間で回せる粒度になっているか
