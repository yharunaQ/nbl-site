# JAC Foundations Note

内部 draft / 2026-03-20 release review

## Short Note

JAC 26フレームは、困りごとを診断名ではなく `反復する職場課題の型` として整理するための地図です。
その全体構造として、`体調レイヤー`、`就職移行レイヤー`、`職場運用レイヤー` の3レイヤーを試験的に紹介します。

## What This Adds

- JAC の背景にある基本的な考え方が見えやすくなる
- 個別相談や checkout より前に、方法論への信頼をつくれる
- 図解ベースで体系的に理解しやすい
- `この地図をどう読むか` と `何はまだ決めないか` が明示され、過剰な期待を防ぎやすい

## Guardrail

- 3レイヤーだけで個別事情を決め打ちしない
- 障害種別の例を固定的な分類として見せない
- 高リスク判断は別途条件確認が必要
