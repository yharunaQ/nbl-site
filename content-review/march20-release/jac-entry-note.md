# JAC Entry Note

内部 draft / 2026-03-20 release review

## Short Note

仕事設計プロダクト群は、困りごとを条件つきの職場設計課題へ変換するための方法論です。
個別相談サービスとして先に売るのではなく、まずは考え方や見立ての入口として公開し、
必要に応じて private な利用や継続運用へつなげる前提で整理しています。

条件整理ドラフトは、当面は Founder が外部依頼対応の中で使う internal tool として扱い、
そこで得たノウハウをもとに将来の operator-assisted / self-serve 可能性を検討します。

## Guidebook Position

guidebook は `買って終わる商品` より先に、
仕事設計の考え方を気軽に試し、職場設計の論点を見直すための `free-first low-friction entry asset`
として位置づけます。

収益の主軸は guidebook 単体販売ではなく、startup fee / recurring fee / bounded private usage に置きます。

## Guardrail

- 個別ケースの最終判断を promise しない
- sales-first に見せない
- guide / guidebook / private layer の役割を混ぜない
