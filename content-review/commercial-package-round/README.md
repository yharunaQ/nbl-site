# Commercial Package Round Review

更新日: 2026-03-16

## Purpose

最初の commercial package を、`受託相談` に戻さずに売れる単位へ変換できているかを review する。

## Review Questions

- first commercial package は one core / two wrappers でよいか
- included / excluded / conditional の切り方は十分明確か
- employer / intermediary の違いが custom consulting drift を生まないか
- boundary and escalation line が package の中に保持されているか
