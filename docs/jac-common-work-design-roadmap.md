# 就業共通設計 化 全面改修ロードマップ（JAC 26フレーム）

更新日: 2026-03-02
前提: `docs/jac-common-work-design-charter.md`

## 全体方針

- 小手先の置換ではなく、26フレーム全体を同一原則で一括改修する。
- 先に仕様を固定し、後で本文を変える（仕様先行）。
- 公開面（ガイド/冊子）と内部面（JAC相談）で表現粒度を分離する。

## フェーズ

### Phase 1: 規範固定（今回）

成果物:
- 改修憲章（目的・ガードレール・完了条件）
- 進行ロードマップ
- 26フレーム言い換え辞書の初期版

完了条件:
- チームが同じ「何を変えて何を変えないか」を参照できる。

### Phase 2: 26フレーム辞書の確定

成果物:
- 各フレームの `旧名称/新名称`
- `旧要約/新要約`
- `旧ポイント/新ポイント`
- `共通設計レイヤー` と `個別最適化レイヤー` の分離文

完了条件:
- 26/26で重複・曖昧語を抑えたMECE運用可能な語彙に揃う。

### Phase 3: 本文への一括反映

対象:
- `pages/jac/guide.tsx`
- `docs/guidebook/manuscript-reader-edition.md`
- 電子冊子生成関連スクリプト

完了条件:
- 画面表示と冊子表示で同じ言い換えが反映される。

### Phase 4: 監査・安全確認

監査軸:
- 根拠整合: 元データとの意味ズレがない
- 安全: 診断決め打ち・過度一般化がない
- 実用: 行動に落ちるポイントが明確
- 区別性: 26フレーム間の境界が明確

完了条件:
- 重大指摘ゼロ、軽微指摘は辞書修正で再現対応可能。

### Phase 5: 公開導線最適化

対象:
- ガイド導入文
- JAC個別相談への接続文
- 販売用ガイドブック説明文

完了条件:
- 「共通設計で全体像→個別相談で条件最適化」の導線が一貫する。

## 週次運用（迷子防止）

1. 辞書更新

## リスクと対策

- リスク: 共通化しすぎて個別配慮義務が薄れる
  - 対策: 二層構造を強制し、法域・条件の記述を削らない
- リスク: 表現統一でフレーム境界が曖昧になる
  - 対策: 境界説明（選ぶ条件・非適用条件）を必須化
- リスク: 部分修正の積み重ねで構造が複雑化する
  - 対策: 辞書を単一ソース化し、本文直編集を禁止
