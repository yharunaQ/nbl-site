## 目的

- 今回のデータ追加と改修が、26フレームのガイドとガイドブック冊子へどう反映されたかを確認するためのメモ。

- 冊子: 26章すべてに `### 4. 進める前に外せない条件` が入り、問い順の章構成で確認できる状態。現在の章数は 26 件。
- 構造判断: 法政策差は別ガードレール層、地域支援オーケストレーションは共通レイヤーまたは別ガイドで扱う方針に揃っている。

## カード別の見方

### 支援接続アーキテクチャ `p-support-service-navigation`

- 更新の要点: 支援接続の詳細運用はカード外へ逃がし、カード内は「期限・責任者つきで見る」までに絞った。
- 法政策: 共通レイヤーへ寄せる / カード内に残す点: 制度要件は法域・自治体確認前提で使う
- 地域支援: 別ガイドへ寄せる / カード内に残す点: 支援接続案は期限・責任者つきで見る
- ガイドでの見え方: 適用条件（法政策・判断線のみ） と 実施条件（地域支援・判断線のみ） の組み合わせで表示される。
- 冊子での確認位置: manuscript-reader-edition.md:1284（章頭） / manuscript-reader-edition.md:1305（4節）

### 実習採用ブリッジ `p-worktrial-transition`

- 更新の要点: 採用後1から4週の支援体制はカード内に残し、制度差の詳細だけを法政策ガードレール層へ寄せた。
- 法政策: 共通レイヤーへ寄せる / カード内に残す点: 実習制度の要件確認は法域前提で行う
- 地域支援: カード内に残す / カード内に残す点: 採用後1から4週の支援体制を実習評価とセットで見る
- ガイドでの見え方: 適用条件（法政策・判断線のみ） と 実施条件（地域支援・詳細表示） の組み合わせで表示される。
- 冊子での確認位置: manuscript-reader-edition.md:1122（章頭） / manuscript-reader-edition.md:1143（4節）

### 相談運用ガバナンス `p-manager-checkin`

- 更新の要点: 相談運用の共通部はカード外へ寄せ、カード内では外部エスカレーション先の有無だけを示す形にした。
- 法政策: 共通レイヤーへ寄せる / カード内に残す点: 社内責任線と相談導線を可視化する
- 地域支援: 共通レイヤーへ寄せる / カード内に残す点: 外部エスカレーション先があるかだけ示す
- ガイドでの見え方: 適用条件（法政策・判断線のみ） と 実施条件（地域支援・判断線のみ） の組み合わせで表示される。
- 冊子での確認位置: manuscript-reader-edition.md:1528（章頭） / manuscript-reader-edition.md:1549（4節）

### 情報開示レイヤー設計 `p-disclosure-boundary`

- 更新の要点: 法政策条件と地域支援の両方がカード境界そのものなので、カード内に厚めに残した。
- 法政策: カード内に残す / カード内に残す点: 共有目的・共有範囲・見直し時点を最小共有で設計する
- 地域支援: カード内に残す / カード内に残す点: 支援体制とセットで開示量を判断する
- ガイドでの見え方: 適用条件（法政策・詳細表示） と 実施条件（地域支援・詳細表示） の組み合わせで表示される。
- 冊子での確認位置: manuscript-reader-edition.md:1442（章頭） / manuscript-reader-edition.md:1463（4節）

### 悪化予兆ハンドリング `p-mental-fluctuation-plan`

- 更新の要点: 法政策の詳細は外へ寄せつつ、再評価導線と戻し先はカード内に残した。
- 法政策: 共通レイヤーへ寄せる / カード内に残す点: 初期サインと段階調整の閾値を明文化する
- 地域支援: カード内に残す / カード内に残す点: 再評価導線と戻し先を示す
- ガイドでの見え方: 適用条件（法政策・判断線のみ） と 実施条件（地域支援・詳細表示） の組み合わせで表示される。
- 冊子での確認位置: manuscript-reader-edition.md:463（章頭） / manuscript-reader-edition.md:484（4節）

## 今の段階で特に問題がないか

- 大きな構造破綻は見えていない。
- ガイドと冊子で、法政策差と地域支援レイヤーの出し分け方針は揃っている。
- テンプレートと記入例まで進めたことで、別ガイドへ逃がした内容も机上で埋められる状態になっている。

## 気にしている点

- まだ `実地で1ケース使った結果` は入っていない。現場で使うと、テンプレートの行数や補助欄の過不足が出る可能性がある。
- 法政策ガードレールは分離方針まで固まっているが、法域別の実務確認項目まではまだ厚くしていない。
- 地域資源の実名ディレクトリはまだ入れていない。ここを入れる段階で、自治体差と更新運用の問題が出る。
