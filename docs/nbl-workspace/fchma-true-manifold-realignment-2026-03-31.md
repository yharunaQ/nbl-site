## Why `48 frameworks` Was Confusing

`8 domains x 6 motifs = 48 frameworks` does **not** mean:

- 48 disability categories
- 48 occupations
- 48 environment types
- 48 final respondent clusters

It means:

- 8 major causal problem domains
- 6 major causal behavior motifs
- their combinations as an upper-level causal reasoning atlas

So the `48` is a **methodological superstructure**, not the manifold result itself.

## What The Real Manifold Base Should Be

The actual manifold should start from the original multidimensional individuality of subjects.

At minimum, the base axes should include:

1. health condition / disability type / diagnosis labels
2. severity / variability / fluctuation
3. age / gender / region / life context
4. employment status / transition stage / work continuity status
5. occupation / task content / role expectation
6. workplace environment / schedule / sensory and interpersonal conditions
7. occupational difficulties and whether they are unresolved, resolved, or absent
8. accommodation and support status
9. disclosure / explanation / communication state
10. future outlook / self-efficacy / desired direction
11. temporal trajectory
12. free-text narrative evidence

In other words:

- disability categories and occupations are **input dimensions**
- not the top-level framework count

## What Counts As True Manifold Analysis Here

To count as a real FCHMA manifold pipeline, the system should do all of the following:

### Stage 1: Joint Subject Representation

Build one subject-level integrated representation from:

- structured numeric and coded data
- categorical and multiselect data
- narrative-derived evidence

This must happen **before** final pattern extraction.

### Stage 2: Neighborhood Structure

Build a local neighborhood structure so that each subject is understood by:

- nearby similar subjects
- nearby but meaningfully different subjects
- bridges between clusters

The manifold is not just global clustering.
It is also the local adjacency structure.

### Stage 3: Multiscale Pattern Extraction

Extract patterns at more than one scale:

- broad basins
- mid-level subpatterns
- local micro-patterns

The current `44` seeds now cover global, local, and micro layers, but they still need to be reviewed and projected into revised product-facing frames.

### Stage 4: Causal Motif Synthesis

For each recurring local pattern, synthesize:

- node structure
- relation structure
- amplifiers
- protectors
- intervention ports
- representative narrative evidence

### Stage 5: Canonical Projection

Only after the manifold-derived local patterns exist should the system:

- map them into the causal framework atlas
- and then map them into the product-facing 3-layer / 26-frame view

## Correct Order

The correct order is:

1. original multidimensional subject data
2. joint manifold representation
3. multiscale local pattern extraction
4. causal atlas occupancy and refinement
5. update proposal for product-facing 26 frames

Not:

1. define product frames first
2. cluster lightly
3. retrofit manifold labels onto them
