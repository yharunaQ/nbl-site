# Commercial Discovery Kit

更新日: 2026-03-16

## Purpose

この文書群は、`NBL OS Pilot` を discovery conversation で説明するための最小セット。

狙いは次の 3 つ。

1. package の中身を 1 ページで伝える
2. excluded items を先に見せて unsafe fit を落とす
3. boundary line を先に見せて誤解を防ぐ

## Kit Components

- one-page package brief
- exclusions list
- boundary one-pager
- discovery call guide

## Use Order

1. one-page package brief を出す
2. 相手が fit しそうなら exclusions list を見せる
3. high-risk 話題に入る前に boundary one-pager を置く
4. discovery call guide で scorecard 項目を回収する

## What This Kit Is Not

- public pricing sheet ではない
- sales close deck ではない
- legal advice document ではない

## Success Condition

- 相手が `NBL OS Pilot` を labor outsourcing でなく operating layer として理解する
- excluded items に強い拒否反応がない
- human review boundary の必要性に合意が取れる
