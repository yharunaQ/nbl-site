# Invisible Disability Series Shortlist

更新日: 2026-03-15

## Purpose

`見えない障害の理解` シリーズの初回公開候補を、5〜8 点に絞る。

初回公開では「病名の網羅」ではなく、以下を優先する。

- 見えない困りごとが直感的に伝わる
- 企業、支援者、周囲の人が読める
- NBL の方法論や支援導線につながる
- 1 つの体験を普遍化しすぎない

## Selected shortlist

### 1. 難病共通

- Asset:
  - `content-inbox/難病共通.png`
  - 代替候補: `content-inbox/難病コミック４コマ/共通横断/難病共通.png`
- Role:
  - シリーズの導入図
- Why now:
  - 病名別の前に「共通する壁」があることを示せる
- Use on site:
  - シリーズの冒頭
  - `見えない障害の理解とは` の導入図版
- Context note:
  - 病名が違っても、仕事上でぶつかる壁には共通構造がある

### 2. 難病×仕事あるある

- Asset:
  - `content-inbox/インフォグラフィック/1204-1 難病×仕事あるある横.png`
- Role:
  - 職場での摩擦ポイントの可視化
- Why now:
  - 企業や同僚が「何が困りごとか」をつかみやすい
- Use on site:
  - シリーズ前半
  - 仕事文脈の具体例として掲載
- Context note:
  - 困りごとは個人の根性不足ではなく、仕事設計と環境条件との相互作用で生まれる

### 3. 体調に“波”がある人と働く

- Asset:
  - `content-inbox/難病コミック４コマ/体調に波のある人/体調に波のある人と働く（横長）.png`
  - 代替候補: `content-inbox/インフォグラフィック/体調の波のある人.png`
- Role:
  - 理解から運用へ橋渡しする図
- Why now:
  - `見えない障害の理解` を、具体的な職場運用につなげられる
- Use on site:
  - シリーズ後半
  - `理解した後に何を変えるか` の実装導線
- Context note:
  - 体調の波は気分ではなく、条件で出力が急落することがある

### 4. からだの中の天気予報

- Asset:
  - `content-inbox/難病コミック４コマ/からだの中の天気予報/からだの中の天気予報.png`
  - 代替候補: `content-inbox/難病コミック４コマ/からだの中の天気予報/からだの天気予報（体内バッテリー）.png`
- Role:
  - 見た目では分からない体内状態を伝える代表図
- Why now:
  - `見えない障害` の説明として最も直感的
- Use on site:
  - シリーズのキービジュアル
  - サムネイルやOG候補
- Context note:
  - 外からは見えにくくても、体内では複数の注意報が同時に起きていることがある

### 5. 見えないバックパック

- Asset:
  - `content-inbox/難病コミック４コマ/見えないバッグパック/IBDバッグパック.png`
- Role:

- Use on site:
  - シリーズ中盤
  - 企業・同僚向け理解コンテンツ
- Context note:
  - 欠勤していないことと、余裕をもって働けていることは同じではない

### 6. 通院も、仕事の一部

- Use on site:
  - 4コマ枠の代表作

- Context note:
  - 通院は「私用」ではなく、働き続ける条件の一部になることがある

### 7. 病名説明ルーレット

- Asset:
  - `content-inbox/難病コミック４コマ/膠原病コミック４コマ/09 病名説明ルーレット.png`

  - 説明負荷の見えにくさを伝える4コマ
- Why now:

- Use on site:
  - 4コマ枠の代表作
  - 同僚・上司向けの理解コンテンツ
- Context note:
  - 当事者は、症状だけでなく「説明し続ける負担」も背負っていることがある

### 8. 難病×支援機関あるある

- Asset:
  - `content-inbox/インフォグラフィック/1204-2 難病×支援機関あるある.png`
- Role:
  - 支援や制度のすき間を示す図
- Why now:
  - NBL が `理解だけで終わらず、支援設計につなぐ` ことを示せる
- Use on site:
  - シリーズの締め
  - 支援導線や相談導線の手前
- Context note:
  - 困りごとは本人だけの問題ではなく、制度や支援の設計でも左右される
