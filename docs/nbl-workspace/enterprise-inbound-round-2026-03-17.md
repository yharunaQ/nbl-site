# Enterprise Inbound Round

更新日: 2026-03-17

## Scope

- 2026年3月20日以降の記事を見て NBL に来る企業担当者を、どんな読者として想定するか
- 障害者雇用の narrow concern だけでなく、より広い `仕事設計 / 組織運用 / AI時代の働き方` 関心へどう開くか
- JAC guidebook を `sales item` ではなく、どんな entry asset として扱うか

## Founder Input

- 記事流入の企業担当者は、障害者雇用だけでなく、もう少し広い組織課題の関心で来る想定
- その方向は NBL の事業定義とも合う
- JAC guidebook は個別相談料の代替より、`お試し` の entry asset に向く
- ただし今は、出し惜しみなく役立つものを出し、レートを超える分だけ有料にする方が自然

## Article Base Alignment

記事ベースでは次が強く出ている。

- 合理的配慮は `思いやり` ではなく `職場設計`
- 雇用率は結果指標
- 最初の実務軸は `中途障害者の継続雇用` と `ニューロダイバーシティ`
- 盲点は `相談・開示しにくさ`
- まず職場設計で改善し、支援連携は `次の一手`

## Revenue Architect Memo

### JAC Entry Posture

- guidebook は `sales-first checkout` ではなく `low-friction entry asset`
- public entry は generous / free-to-start
- private usage、継続利用、rate 超過、private workspace 接続で有料化する
- article の論旨に合わせ、最初に売るより、まず `役立つ職場設計の入口` として出す

### Why

- NBL の価値は、最初の小さな役立ちを出し惜しみなく見せた上で、継続利用や private layer で recurring に変える方が社会OSらしい
- 初手から guidebook 販売に寄ると、記事流入の enterprise reader に `小売` と誤認されやすい

## Safety And Boundary Lead Memo

## What is currently usable

- Usable now (with conditions):
  - `障害者雇用に閉じない` ことを、仕事設計 / 組織運用 / 支援設計へ広げて書く
  - JAC guidebook を `低摩擦の入口 asset` として再定義する
  - free-first / overage-later を internal revenue posture に置く
- Not yet usable:
  - 個別ケースの最終判断まで広く扱うように見える wording
  - guidebook checkout を public 主導線に戻すこと
  - 法的責任や個別事情を薄める efficiency rhetoric

## Integrated Recommendation

- 3月20日以降の流入に備える public 入口は、`障害者雇用サイト` より `働きづらさと仕事設計を扱うAI-native social OS` に寄せる
- ただし wording の核は `AI` 単体でなく `職場設計`
- current public site でも、safe な範囲で `企業・組織の方へ` の入口を作る
- JAC guidebook は `buy now` ではなく、`free-first / overage-later` の entry asset として internal posture を更新する
