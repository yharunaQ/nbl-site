# JAC Foundations Round

更新日: 2026-03-17

## Purpose

3月20日までの public-safe な追加説明として、JAC 26フレームの `3レイヤー` と背景インフォグラフィックを試験的に紹介する。

## Why Now

- JAC は方法論として重要だが、現在の public 面では `何が基礎地図なのか` が見えにくい
- 3レイヤーと基礎図解があると、sales-first でなく考え方の厚みとして信頼が出しやすい
- 既存の図版資産だけでも、public-safe な最小紹介面を組める

## Public-safe Scope

- 26フレームの全体地図としての 3レイヤー
- `個人の根性論から場の設計へ`
- `仕事のコンディションマップ`
- `障害者雇用の質の指標`
- `この地図の読み方` と `個別化するときに見る軸` の説明

## Guardrails

- 診断名でカードを決め打ちしない
- 26フレームだけで個別事情を確定したように見せない
- 法政策差や高リスク判断を、このページ単独で処理しない
- JAC 個別相談や checkout を主導線に戻さない

## Implementation

- public page:
  - `/jac-foundations`
- source:
  - `docs/26cards/*.png`
  - `content-inbox/...` の基礎図解

## Role In March 20 Sprint

- top page の自然な追加説明の先
- `補足ページ` よりも `JAC の考え方の土台` を返す面
- review 対象としては `JAC entry note` とセットで確認する

## Current Page Shape

- 先に `何が分かるか / 何はまだ決めないか` を示す
- 3レイヤーの前に `この地図の読み方` を置く
- 各図版は `その図を置く理由` と `見るポイント` を添える
- 図をそのまま大きく貼るだけでなく、説明文を主役にして信頼感を補う
