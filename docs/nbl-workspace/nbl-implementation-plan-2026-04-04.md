# NBL 次期公開 実装計画

作成日: 2026-04-04

---

## 実行の考え方

AIエージェントが進める作業と、人間のレビューが必要なゲートを明確に分ける。

- **AI実行**: コンテンツ草稿・コード実装・スクリプト更新はAIが進める
- **人間ゲート（🔑）**: 創業者の判断・承認・レビューが必要な箇所。ここが律速になる
- **並列可能**: 依存関係のない作業は同時並行で進める
- **依存あり**: 前の作業の完了を待つ必要があるもの

### B2：/guide ページ実装（27フレームWeb表示）

**内容**: `jac-27-frame-edition.md`をWebページとして表示する
- `/guide` トップ（3設計層の地図 + 27フレーム一覧カード）
- `/guide/[frame-id]` 各フレーム個別ページ
- フレーム番号（Ⅰ-01等）をURLスラッグとして使用

**実装方式の選択**:
- Option X: mdファイルを静的生成（Next.js getStaticProps + remark）
- Option Y: フレームデータをJSONで管理し、コンポーネントで表示

**推奨**: Option X（mdからの静的生成）。既存の`jac-27-frame-edition.md`がそのままソースになり、更新が容易。

**依存**: なし（独立して着手可能）
**人間ゲート**: 表示確認
