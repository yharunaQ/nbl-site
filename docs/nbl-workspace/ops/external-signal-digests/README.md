# External Signal Digests

外部 signal の定期要約を置くフォルダ。

想定する対象は次の 4 track。

- 企業
- 当事者 / 難病患者
- 支援者 / 支援機関
- 研究 / 政策

各 digest では、raw signal の羅列ではなく、最低限次を分けて残す。

- What surfaced
- What seems structural
- What remains partial or risky
- Next validation move
- Founder boundary

ファイル名は `YYYY-MM-DD.md` を基本とする。
