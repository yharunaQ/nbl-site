# Inventory Queue

更新日: 2026-03-15

## Next loop after site architecture

全体設計を provisional に置いたあとは、stream ごとに content inventory に戻る。

推奨順:

1. `What We Do`
   - 理由: 初期公開の CTA と offer を支える中核だから
   - 対象: `Hero`, `Phase1`, `Services`, `ProductJac` の一部
2. `Resources`
   - 理由: 大量の図解・4コマ・動画を適切に束ねる必要があるから
   - 対象: `見えない障害の理解`, その他インフォグラフィック, YouTube, Reports
3. `JAC`
   - 理由: 中核 stream だが、NBL 全体の一部として見せ方を調整する必要があるから
   - 対象: `/jac`, guide, product copy
4. `About`
   - 理由: Vision や CAN BY DESIGN を、主導線を壊さない位置に置く必要があるから
   - 対象: `Vision`, `Campaign`, founder note
5. `Hold`
   - 理由: いま public に出さないものを明確にしておく必要があるから
   - 対象: DAO, pricing draft, market vision draft, experimental docs

## Rule of return

- 全体設計で迷ったら、必ず stream 単位の inventory に戻る
- inventory で迷ったら、`Home / What We Do / Resources / JAC / About` のどこに置くかで考える
- どこにも自然に置けないものは、いったん `hold`
