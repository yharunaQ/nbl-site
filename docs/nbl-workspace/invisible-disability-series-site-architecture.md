# Invisible Disability Series Site Architecture

更新日: 2026-03-15

## Goal

`見えない障害の理解` を、NBL サイト内の 1 シリーズとして公開する。

このシリーズは、次の 3 つをつなぐ。

- 見えにくい lived experience の理解
- 周囲や職場が起こしやすい誤解の解消
- 実装・運用への橋渡し

## Recommended placement

- Home:
  - シリーズへの短い導線のみ
- Primary destination:
  - `Resources` または `Insights` 内のシリーズページ
- Optional secondary destination:
  - `What We Do` / `Approach` から関連リンク

## Context note template

各作品には、短い注記を付ける。

### Required fields

- `What this piece highlights`
- `Why it matters at work`
- `Do not overgeneralize`
- `Related approach or resource`

### Example

```md
What this piece highlights:
見た目では分かりにくい疲労や痛みの存在

Why it matters at work:
「元気そう」に見えることを理由に、配慮や調整が不要だと誤解されやすい

Do not overgeneralize:
困りごとの出方は人や仕事条件によって異なる

Related approach or resource:
体調の波に対応する運用設計 / 合理的配慮の考え方
```

## First release recommendation

初回公開は、1 ページに絞る。

- 1 シリーズページ
- 5〜8 点の図版
- 各図版に短い context note
- 関連動画は 1 本まで

この構成なら、重要コンテンツとして十分見せつつ、情報過多を避けられる。
