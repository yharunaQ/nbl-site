# Partner Candidate Pipeline

更新日: 2026-03-16

## Purpose

この文書は、実名候補がまだ未入力でも discovery ops を進められるようにするための匿名 pipeline。

## Slot Design

- `A1`
  - primary target
  - employer-facing intermediary
- `A2`
  - primary target
  - employer-facing intermediary
- `B1`
  - secondary target
  - design-forward employer
- `C1`
  - comparison target
  - research / policy lighthouse

## Why Anonymous Slots First

- network convenience で相手を選ばないため
- target ratio を崩さないため
- 実名が入る前に、必要 evidence と red flags を固定するため

## Slot Requirements

### A1 / A2

- employer network がある
- named operational owner がいる
- contextual review / escalation に前向き
- repeated use が見込める
- low automation pressure

### B1

- named internal sponsor
- workflow redesign appetite
- 1 本目の workflow lane を絞れる
- boundary line を受け入れる

### C1

- legitimacy / translation value
- field or network access
- learning value
- revenue lead ではなく comparison role

## Pipeline Rule

- まず slot に必要条件を満たすかを見る
- 次に outreach material を送る
- call 後に scorecard を埋める
- stop rule に触れたら slot ごと hold する

## Completion Condition

- A1 / A2 / B1 / C1 の各 slot に 1 候補ずつ入る
- 4 件の scorecard が埋まる
- provisional ranking が出る
