## 設計の共通原則（全レイヤー）

**情報圧縮によるフレームワーク × 自己効力感の向上**が全レイヤーの設計軸。

| レイヤー | フレームワーク | 対象の自己効力感 |
|---|---|---|
| Layer A | 30フレーム（当事者の困難を構造化） | 当事者が自分の状況を整理できる |
| Layer B | 支援者実践フレームワーク（有効支援を構造化） | 支援者が「できる」と感じる |
| Layer C | 組織変革フレームワーク（管理職の取組を構造化） | 管理職が「やるべきことがわかる」と感じる |

## Layer B：支援者向けプロダクト

### 目的

意欲のある支援者（Q2: 71.9%）が、従来の効果的でない就労支援と対比させて、効果的な就労支援のポイントを確実にマスターし、**「できる」という自己効力感を有意に向上させる**。

### 対象

- Q2支援者（連携志向の理念はあるが実施できていない: n=2,196）
- 特にC0a（医療機関・制度的孤立型）

### プロダクト形態

**Q1支援者の実践知を情報圧縮したフレームワーク**

30フレーム（当事者側）と同じ構造で、支援者の実践知識側を圧縮・整理したもの。

構成要素の根拠（`data/analysis_ready/supporters/` のFCHMA分析）:

| 構成要素 | データ根拠 |
|---|---|
| Q1実践 vs Q2課題語りの対比 | narrative分析: やりがい差+0.128、医療就労ギャップ認識差-0.024 |
| 効果的な学習経路（推奨順序） | 問12: 実践経験+0.199、機関内研修+0.174、ピア交流+0.159 |
| 効果的な連携体制（推奨順序） | 問13: なかぽつQ1参加率37.4%、HWチーム38.5% |
| Q2→Q1転換の3入口と壁突破策 | `q2-to-q1-transition-pathway-2026-04-02.md` |

### 「従来との対比」の内容

「従来の非効果的な状態」はQ2のnarrativeから実データで導出済み：

| 効果的でない状態（Q2の語り） | 効果的な実践（Q1の語り） |
|---|---|
| 「医療と就労のギャップを認識している」 | 「地域連携体制の情報提供をしている」 |
| 「支援の必要性を感じる」 | 「就職後のフォローをこうしている」 |
| 「知識・スキルが不足していると感じる」 | 「就労支援のやりがいを感じている」 |

### Layer Aとの関係（重要）

- **「次の一手」AIアシスタント** → Layer A（`/jac/next`）に統合。Layer Bには含まない。
- Layer Bは「AI相談」ではなく「フレームワークによるマスタリー」が中心。

### エビデンス基盤（更新済）

- **使用**: `data/analysis_ready/supporters/` のFCHMA分析結果（toku18 n=3,053）
- **不使用**: supports.md・IPS/GLM概念（Layer A設計時の旧基盤。Layer Bの根拠としては不適切）

## Layer C：管理職向けプロダクト

### 目的

基礎的研修やサービス基準で定められていながら、具体的に支援者が動きやすい組織づくりができない管理職が、やるべきことを確実に実施し、**「できる」という自己効力感を有意に向上させる**。

### 対象

- 支援機関の管理職・機関長（特にC0b: 機関ミッション=0.192、上司=0.192の完全孤立型機関）
- 「基礎的研修・サービス基準は知っている」が「組織づくりができない」層

### プロダクト形態

**① 組織診断ツール**

「あなたの機関はなぜ支援者が動けないか」を可視化。
根拠: 問14 制度的障壁分析（Q1-Q2差）

| 診断軸 | Q1-Q2差 | 優先順位 |
|---|---|---|
| 上司・職場文化 | +0.131 | 1（最大） |
| 機関ミッション・法令 | +0.118 | 2 |
| 業績評価基準 | +0.117 | 3 |
| 資金・報酬基準 | +0.110 | 4 |
| 専門職規範 | +0.101 | 5 |

**② 組織的取組フレームワーク（情報圧縮）**

管理職がやるべき具体的取組を、30フレームと同様の情報圧縮方式で整理。
既存知識基盤: `g3-org-change-knowledge-2026-04-02.md`

### 制度知識の状態

`g4-medical-reimbursement-framework-2026-04-02.md` が作成済みだが、**概念整理のみ**。
具体的な診療報酬点数・最新改定内容は未収集（追加収集が必要）。
