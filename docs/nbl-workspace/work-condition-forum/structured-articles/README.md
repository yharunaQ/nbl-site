## Format Decision

このディレクトリは、短い要約ではなく、小見出し付きの本文記事を置く。

Role:

- `editorial-essays` の短い文章を核にして、発表場面、誤読、仕事条件、専門ノート、参加者別問いを再接続する。
- 動画・音声・インフォグラフィック・スライドに続く「文章でじっくり理解する」認知チャンネルとして使う。
- 1本ごとに、要約より詳しく、論文より読みやすく、構造が見える文章にする。
- public approval, legal/medical/employment/accommodation finality, current policy claims are outside this artifact.

## Heading Rule

- 見出しは一般的な構造ラベルではなく、その節の一言要約にする。
- 見出しだけを読んでも、記事全体の主張の流れが分かるようにする。
- 詳しく知りたい読者が、見出し下の本文で背景・理由・例・確認点を読める形にする。
- 関連資料と境界メモも、機能が分かる見出しにする。

## Condition List Rule

- 条件リストは、条件名だけの索引にしない。
- 各項目は「条件名：具体説明。補足説明。」の形にして、読者が仕事場面へ置き換えられるようにする。
- 条件はチェックリストではなく、本人、仕事、環境、支援、時間、制度、評価の関係を読む入口として扱う。

## Rendering Decision

- Markdown is the storage/editing format for these structured drafts, not the reader-facing text surface.
- Reader-facing links from the virtual forum should point to `/preview/work-condition-forum-text/[id]`, where headings, paragraphs, quotes, and lists are rendered as a laid-out article page.
- Raw Markdown asset links may remain useful for internal production, but they should not be the main text route for the forum preview.
- The forum listing page treats each full-width presentation row as the article entrance. Video, slide, infographic, and text links are not shown as separate row actions.
- The article page flow is: hero summary, infographic with same-page enlarged view, video/slide navigation, article body, embedded video, next presentation, and boundary footer.
- Slide placement inside article sections remains a later editorial refinement. The current shippable preview uses the slide PDF link as the bounded fallback.
- The main forum page should read as a virtual academic forum front page: forum name, aim, generated fictional-city venue image, session cards, and presentation cards. Internal production notes belong in docs, not in the reader-facing page.
