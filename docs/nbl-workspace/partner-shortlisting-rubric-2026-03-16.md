# Partner Shortlisting Rubric

更新日: 2026-03-16

## Purpose

この rubric は、A1 / A2 / B1 / C1 に候補を入れる前に、`入れてよい候補か` を先に判定するためのもの。

## Use Rule

- まず `knockout condition` を見る
- 次に `core fit` を 3 段階でみる
- 最後に slot ごとの補助条件を確認する

## Knockout Conditions

次のどれかが強い場合、候補は slot に入れない。

- labor outsourcing expectation が強い
- final employment judgment support を期待している
- diagnosis-only framing が強い
- named owner の仮説が立たない
- repeated use でなく one-off support しか想定できない

## Core Fit

### 3 = Strong

- repeated use potential が明確
- owner が明確
- boundary acceptance の見込みが高い
- low automation pressure

### 2 = Partial

- 方向性は合うが owner か boundary の一部が未確認

### 1 = Weak

- one-off 寄り
- owner 不明
- boundary risk が高い

## Slot-Specific Check

### A1 / A2

- employer network
- contextual review or escalation willingness
- intermediary としての translation value

### B1

- workflow redesign appetite
- 1 本目の lane を絞れる
- sponsor clarity

### C1

- legitimacy / translation value
- learning value
- commercial lead でないことを理解している

## Recommended Rule

- A / B は `core fit 2 以上` かつ `boundary readiness` が弱くないこと
- C は revenue fit より legitimacy / learning fit を優先する
