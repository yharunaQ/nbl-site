## 2. 調査分析から導かれた因果構造との照合

### 2.1 因果構造の再確認（5レイヤー）

```
L1: 制度設計レベル
  機関ミッション(+0.118) → 業績評価基準(+0.117) → 資金・報酬基準(+0.110)
    ↓
L2: 組織マネジメントレベル
  上司・職場文化(+0.131) [最大阻害要因]
    ↓
L3: 専門性形成レベル
  実践経験蓄積(+0.199) × 支援者間交流(+0.159) × 専門機関助言(+0.154) × 機関内研修(+0.174)
    ↓
L4: 地域連携体制参加レベル
  就労移行（Q1:31.6% vs Q2:14.6%）× 就業生活センター（Q1:37.4% vs Q2:21.0%）× HWチーム（Q1:38.5% vs Q2:23.2%）
    ↓
L5: 実施可能性・専門性有効感
  「実施できる」状態 → やりがい発生 → さらに実践（正のフィードバックループ）
```

## 4. 既存知識の「繋ぎ直し」計画

既存知識（supports.md + HW事例 + GLM結果）は、**ケースレベルの「何をするか」**に特化している。
調査分析が明らかにした知識ニーズは、**構造・組織レベルの「なぜ始められないか」**。

この2層を繋ぐ「橋渡し知識」が不足している。

### 橋渡し知識の設計

```
【既存知識層】                    【橋渡し知識】                    【新規知識層】
「何が有効か」（supports.md）  ← →  「どうすれば始められるか」  ← →  「なぜ始められないか」（因果構造）
  ↓                                （連携開始プロトコル）              ↓
 ケース介入の質                       ↓                            組織・制度変革
  （L3-L5）                   L4: 連携体制参加経路              （L1-L2）
```

**橋渡し知識の具体内容**：

1. **「医療機関の支援者が就労支援に参入するためのファーストステップ」**
   - 「自前でやらなくていい」の明示
   - 「紹介先に連絡する」という最小行動の具体化
   - 「報告書の書き方」「ケース会議への参加方法」

2. **「連携ネットワークへの接続コスト低減」**
   - 問13データ: Q2支援者でも就労移行を「知っている」割合32.2%
   - 問題は知識不足より「どうやって連絡するか」の実行コスト
   - → 具体的な初回接触スクリプト・情報共有テンプレート
