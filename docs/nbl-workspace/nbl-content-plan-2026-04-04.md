# NBL コンテンツ制作計画

作成日: 2026-04-04
公開方針: Phase 1・Phase 2 を一括公開

---

## 制作の優先原則

1. **根拠がないコンテンツは作らない** — すべての主張はデータ由来の知識ネットワークに紐付ける
2. **断言する** — 研究者的な留保表現（「〜かもしれない」）は使わない
3. **短く** — 一文で言えることを二文で書かない
4. **データは2段目** — 主張を先に、根拠は後

### P1-1 ホームページ

**ファーストビュー:**
```
[見出し]
就労の詰まりは、仕事と環境の設計で解ける。

[サブテキスト]
日本の当事者・支援者のデータから導いた、インクルーシブ就労支援の実践知識。
27のフレームと対話AIが、現場の一手を示します。

[ボタン2つ]
今の事例を相談する（→/jac）　　フレームを調べる（→/guide）
```

**セカンドブロック（数字で問題の実在を示す）:**
```
71.9%  就労支援者のうち、意欲はあるが実施できていない割合
最大6倍  都道府県によって就労支援実践率に生じる格差
9,000件超  当事者・支援者の実データをもとに開発した知識
```

**サードブロック（4入口）:**
```
今の相談事例を整理したい   → はたらく相談室（AI）
典型的な困難を調べたい     → 仕事設計ガイドブック
支援実践の全体像を知りたい  → 実践知識を学ぶ
職場・組織の環境を変えたい  → 職場・組織設計
```

**ライティング注意:**
- 「〜のための」「〜を支援する」という受動的表現を使わない
- 能動的・断言的に書く
- 「障害者向け」「支援者向け」という区画を作らない

### P1-2 はたらく相談室 ランディングページ（/jac）

**目的:** 「何ができるか」を正確に伝え、使い始めるハードルを下げる

**構成:**

```
[見出し]
はたらく相談室

[説明 3行]
就労の困難を話すと、何が起きているかが構造的に整理されます。
27のフレームと日本のデータに基づき、具体的な一手を示します。
最終判断は、あなたと支援者が持ちます。

[使い方の例（3パターン）]
「体調が変動して、仕事のペースが保てない」
「どう伝えればよいかわからず、配慮を依頼できていない」
「支援につながりたいが、どこから始めればよいかわからない」

[始めるボタン]
相談を始める →

[注意事項 小さく]
・入力内容は診断に使用されません
・相談内容の改善のため匿名で分析する場合があります
・緊急時・医療的判断が必要な場合は専門機関にご相談ください
```

### P2-1 71.9%問題の解説

**タイトル案:** 「71.9%の支援者が、意欲はあるが実施できていない理由」

**構成:**

1. **事実の提示**（300字）
   - 71.9%という数字の出所と意味
   - Q1（実践できている）・Q2（意欲あり・実施できず）・Q3/Q4（無関心・対立）の4分類
   - Q2が最大多数であるという事実

2. **なぜ実施できないのか：5層の因果構造**（400字 + 図）
   - L1 制度設計の問題
   - L2 組織環境の問題（上司・文化・評価基準）
   - L3 専門知識の不足
   - L4 地域連携の欠如
   - L5 実施可能性の壁
   - → 個人の問題ではなく構造的問題である

3. **知識ネットワークがなぜ有効か**（200字）
   - 実践経験の代替として機能できる（r=0.327）
   - 地域格差の解消装置として機能できる

4. **次に読む**
   - → Q1支援者は何が違うのか
   - → どの連携機関がQ1転換につながるか

**根拠:** toku18 4象限分析・5層因果構造・q2-to-q1-transition-pathway文書

---

### P2-2 Q1とQ2の実践の違い

**タイトル案:** 「Q1支援者は何が違うのか——実践の語りから見えるもの」

**構成:**

1. **対比表**（メイン）

| Q2の語り（課題を語る） | Q1の語り（実践を語る） |
|---|---|
| 「医療と就労のギャップを感じている」 | 「地域連携体制の情報提供をしている」 |
| 「知識・スキルが不足していると感じる」 | 「就労支援にやりがいを感じている」 |
| 「支援の必要性を感じる」 | 「就職後のフォローをこうしている」 |

2. **「語り」の違いが示すもの**（300字）
   - 問題の認識の仕方が違う
   - Q1は「何が必要か」を語り、Q2は「何が難しいか」を語る
   - この違いは意欲の差ではなく、実践経験の有無から来る

3. **Q2→Q1転換の入口**（200字）
   - 最も効果的なのは実践経験（+0.199）
   - 次いで機関研修（+0.174）・ピア交流（+0.159）
   - 「まず知識を入れる」より「小さな実践をすぐ始める」

**根拠:** toku18 narrative分析（やりがい差+0.128等）・Q12データ

---

### P2-3 効果的な実践知識の積み方

**タイトル案:** 「Q1転換につながる学び方——データが示す5つの経路」

**構成:**

1. **効果の順位**（図 + 短い解説）
```
1位 実践経験（+0.199）
2位 機関内研修（+0.174）
3位 支援者間のピア交流（+0.159）
4位 地域専門機関からの助言（+0.154）
5位 Webリソース（+0.106）
```

2. **「実践経験が最も効く」の意味**（250字）
   - 実践経験の蓄積が地域Q1率と最も相関（r=0.327）
   - 「理解してから実践する」より「実践しながら理解する」
   - 知識AIはこの「実践経験」のバーチャル代替として機能できる

3. **機関内研修・ピア交流の設計**（200字）
   - 「参加するだけ」でなく「判断を共有する」ピア学習が重要
   - 機関研修の内容・形式が転換効率に影響する

4. **Webリソースの位置づけ**（100字）
   - 単独では効果が最も低い（+0.106）
   - 実践・ピア交流と組み合わせることで効果が出る
   - NBLの知識プラットフォームはここを変える

**根拠:** Q12データ・g5-peer-learning-design文書

---

### P2-4 どの連携機関がQ1転換につながるか

**タイトル案:** 「連携先の選択が実践を変える——Q1転換差ランキング」

**構成:**

1. **Q1転換差ランキング**（メイン図）
```
就労移行支援事業所          +17.0pt（最高）
障害者就業・生活支援センター   +16.4pt
ハローワーク（チーム支援）    +15.3pt
難病相談支援センター         +3.1pt
```

2. **なぜこの順位になるか**（各機関の特徴・300字）
   - 就労移行支援：訓練→求職→定着の全工程に関与できる
   - 就業生活支援センター：企業アプローチ+就労・生活一体相談
   - HWチーム：就職活動の直接支援
   - 難病相談支援センター：難病特有の専門性は高いが連携範囲が限定的

3. **「参加しているのに変わらない」問題**（200字）
   - 参加するだけでは不十分。参加の質が重要
   - 「判断を共有する」連携が転換につながる
   - （→P3-1「参加の質」へのリンク）

4. **どう使うか**（150字）
   - Q1転換を目指す支援者が「次に連携を深めるべき機関」を選ぶ指針に
   - 機関の管理者が「どの連携体制を優先的に参加すべきか」を決める根拠に

**根拠:** Q13データ（Q1参加率-非参加者Q1率差）

---

### P2-5 地域格差の構造

**タイトル案:** 「都道府県によって最大6倍の差がある——就労支援実践率の地域格差とその構造」

**構成:**

1. **事実の提示**（図 + 100字）
   - 都道府県Q1率の分布（ヒストグラムまたはヒートマップ）
   - 最高と最低で6倍の差
   - 地域名は出さず分布として示す

2. **「意識の差」ではない**（300字）
   - 格差の主因は「実践経験の蓄積環境」（r=0.327）
   - 機関ミッション・上司文化との相関はほぼゼロ（都道府県レベルでは）
   - → 個人の努力では解消できない構造的問題

3. **正のフィードバックループ**（200字 + 図）
   - Q1支援者が多い地域 → 周囲への実践知伝播 → ピア学習 → Q1が増える
   - 下位地域にはこのループが存在しない
   - 知識プラットフォームはバーチャルなQ1環境として機能できる

4. **「参加の質」パラドックス**（200字）
   - 連携体制への参加率が最も高い地域ブロックで転換効率が最低
   - 「参加しているのに変わらない」問題の地域レベルの証拠

**根拠:** 地域別Q1率分析・regional-variation-analysis文書

**可視化の設計注意:**
- 都道府県のヒートマップは「分布の幅を示す」目的で使う
- 特定地域を「良い/悪い」と評価する表現は一切使わない
- 図のタイトルは「就労支援実践率の地域分布」等、中立的に

---

### P2-6 日本のデータが示すインクルーシブ就労支援

**タイトル案:** 「日本のデータが独立に導いた、インクルーシブ就労支援の原則」

**構成:**

1. **発見の意味**（200字）
   - 日本の当事者・支援者データを分析した結果、IPS/SE（国際的な就労支援モデル）と同じ構造が独立に見出された
   - これは「海外から輸入した理論」ではなく「日本の実態から導いた知識」であることを意味する
   - 日本の文化・制度・地域特性に合わせた精度で示せる

2. **日本データが示す原則（5つ）**（各100字）
   - 「準備してから就職」より「就職しながら準備」が成功率が高い
   - 個人の配慮より仕事と環境の設計が先
   - 支援者の実践経験が最大の転換因子
   - 連携の「参加」より「参加の質」が重要
   - 地域格差は個人の努力で解消できない構造問題

3. **IPS/SEとの整合（独立検証として）**（200字）
   - IPS/SE（RCT: 競争的雇用獲得率が従来型の2〜3倍）は日本データの構造を独立に確認している
   - 日本固有のデータが先にあり、IPS/SEがそれを国際的に裏付ける関係
   - 「IPS/SEを導入しよう」ではなく「日本のデータが示す実践を深めよう」

4. **実践への含意**（200字）
   - 27フレームの設計思想への接続
   - はたらく相談室AIの知識基盤への接続

**根拠:** 仕事設計ガイドブックの設計思想・IPS/SE整合記述・regional-variation-analysis

## 制作スケジュールの考え方

ソロ+AI制作の場合、各コンテンツの制作所要時間の目安：

| 種類 | 目安 |
|---|---|
| テキスト記事（500〜800字） | 1〜2セッション |
| データ可視化（静的図） | 1セッション（図の設計）+ 実装時間 |
| ランディングページ（UI設計含む） | 2〜3セッション |
| ガイドブックHTML/PDF | スクリプト更新1セッション |

**推奨制作順序:**

```
[Week 1]
P1-1 ホームページコピー → P1-2 はたらく相談室LP → P1-3 ガイドブックトップ

[Week 2]
P2-1 71.9%解説 → P2-2 Q1/Q2の違い → P1-4/P1-5 About・データ説明

[Week 3]
P2-3 学び方 → P2-4 連携機関ランキング → P2-6 IPS/SE日本版

[Week 4]
P2-5 地域格差（可視化含む）→ 全体レビュー → 公開

[公開後]
P3-1〜P3-3（補完コンテンツ）→ D-1 組織診断ツール（別途）
```
