# JAC Tag Taxonomy Rule

## 今回の確認で分かったこと

- `フルタイム勤務` のような勤務時間条件は、guidebook / 26フレーム / data2 / 記述回答 / web系資料で繰り返し出てくる重要論点だった。
- それにもかかわらず、JAC の入力タグでは first-class tag になっていなかった。
- 原因は、勤務時間・勤務日数・シフト・残業が、`休憩` や `時間制約・納期` に吸収され、独立した就労成立条件として扱われていなかったため。

## 現状への率直な評価

- 既存タグは、相談を素早く整理する入口としては有用。
- ただし、網羅性や代表性が明示的ルールで保証されていたわけではない。
- 実態としては、開発の過程で有用だった論点を `pages/jac.tsx` と `lib/jac/tagDictionary.ts` に手作業で積み上げてきた部分が大きい。
- したがって、現状タグは「有用だが、まだ制度化されていない taxonomy」だった。

## これからの決定原理

タグは診断名リストではなく、`支援設計が変わる条件` を表すものとして決める。

最低限、次の 5 面を外さない。

1. `situation`
就職活動中か、在職中か、復職前後か。

2. `task`
何の場面・作業・勤務条件で困難が生じやすいか。

3. `symptom`
どの心身機能や認知・感覚の影響が出ているか。

4. `environment`
環境・設備・制度・情報経路のどこが条件になっているか。

5. `preference`
本人が何を守りたいか、何を受け入れやすいか。

## 網羅性・代表性の判定ルール

新しいタグは、少なくとも次のうち複数を満たすときに昇格させる。

- 26フレームや guidebook で再帰的に出てくる
- data2 / 記述回答 / web-cache / support catalog でも繰り返し出てくる
- そのタグがあることで、追加質問が変わる
- そのタグがあることで、個別調整案や支援連携案が変わる
- 特定障害だけの特殊論点ではなく、複数障害群でも就労成立条件として現れる

## 今回昇格したタグ

- `勤務時間・勤務日数（フルタイム/短時間）`
- `シフト・夜勤・勤務時刻`
- `残業・連続勤務`
- `身体操作・実作業負荷（立位・運搬・手作業）`
- `安全・危険業務・緊急対応`
- `指示・連絡の明確さ（手順書/見本/確認）`

これは「勤務時間の話題を増やした」のではなく、`就労成立条件としての時間設計` を独立論点として認めた、という位置付け。

追加 3 項目の意味は次の通り。

- `身体操作・実作業負荷` は、移動アクセスや机・椅子だけでは拾えない `立位・運搬・上肢操作・細かな手作業` の負荷を見るための入口。
- `安全・危険業務・緊急対応` は、一般的な困りごとではなく、事故・急変・停止判断・危険業務の可否が就業可否を変える条件を先に押さえるための入口。
- `指示・連絡の明確さ` は、診断や本人能力の問題に還元せず、`手順書・見本・チェックリスト・完了条件` の設計で変わる環境条件を独立して見るための入口。

## Step 3 へ回すもの

重要でも、次は Step 2 タグではなく Step 3 以降で扱う。

- 情報開示の線引き
- ケース会議や相談運用の頻度設計
- 地域支援の具体的な役割分担
- 制度適用や法域判断の詳細

## Step 4 との関係

この見直しは Step 4 の本丸とも直結する。

- タグが粗いままだと、取得する追加質問も粗くなる
- 追加質問が粗いままだと、Step 4 の具体化も浅くなる
- つまり Step 4 の抜本改善には、citation 再設計だけでなく、入口 taxonomy の精度向上も必要

ただし、Step 4 の最大課題は依然として `どの資料を direct basis として出すか` の再設計であり、今回のタグ改善はその前段の整備である。
