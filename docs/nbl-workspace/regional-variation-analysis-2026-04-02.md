# 地域差分析：支援者Q1実践率の都道府県・地域別変動

作成日: 2026-04-02
データ: toku18 n=3,053（都道府県コード完全一致率99.8%: n=3,048）

---

## 最重要発見：地域差は6倍、最強予測因子は「実践経験」

### Q1実践率の地域格差

| 指標 | 値 |
|---|---|
| 全国平均Q1率 | 19.2% |
| 最高 | **北海道 33.0%** |
| 最低 | **香川 5.3%** |
| 標準偏差 | 0.061 |
| 最大格差 | **6.2倍** |

→ **「就労支援の実践者比率」は地域によって最大6倍の格差がある。**
これは支援者個人の意欲や能力の差ではなく、地域の構造的環境の差。

### 地域ブロック別Q1率

| 地域ブロック | Q1率 | Q2率 | n |
|---|---|---|---|
| **北海道・東北** | **24.4%** | 69.7% | 505 |
| 関東 | 23.0% | 68.5% | 569 |

| 九州・沖縄 | 17.7% | 74.0% | 481 |

→ 中国・四国が最もQ2率が高い（78.2%）。「意欲があるのに実施できない」支援者が最も集中。

## 地域差の原因：何が違うのか

### 都道府県Q1率との相関分析

| 要因 | Q1率との相関 r | 解釈 |
|---|---|---|
| **実践経験の蓄積** | **+0.327** | **最強の予測因子** |
| 連携志向理念 | +0.105 | 弱い正相関 |
| 機関ミッション | -0.099 | ほぼ無関係 |
| 上司・職場文化 | -0.083 | ほぼ無関係 |

### 解釈：「地域差 ≠ 意識の差」

**機関ミッション・上司文化の相関がほぼゼロ**というのは決定的な所見：
- 個人レベルでは上司・職場文化がQ1-Q2の最大差（+0.131）だが
- **都道府県レベルでは実践経験（r=0.327）が圧倒的**

→ **地域差の正体は「その地域に実践を蓄積できる環境があるか」の差。**

上位県（北海道・関東）は「Q1支援者が多い → 周囲への実践知の伝播 → ピア学習 → 次の世代がQ1になりやすい」という正のフィードバックループが機能している。

下位県（中国・四国・九州）はその蓄積が薄い。

## 知識ネットワークへの含意

### 含意1: 知識ネットワークは「実践経験の代替」として機能できる

- 北海道33% vs 香川5.3%の差の主因は「実践経験の蓄積量」
- 知識AIが「実践事例の知識・ピア学習の代替」を提供できれば、下位地域の支援者がバーチャルな実践経験を積める
- **「知識ネットワーク = 地域格差の解消装置」として位置づけ可能**

### 含意2: 中国・四国・九州は最優先介入地域

- Q2率78.2%（中国・四国）: 最も「解放されるべき潜在的実践者」が多い
- これらの地域の支援者が知識AIにアクセスできれば、構造的格差を短期間で縮小できる

### 含意3: 上位地域の実践知をネットワーク化する

- 北海道・関東の支援者が持つ実践知（高密度事例・ピア学習文化）をナレッジベース化
- 下位地域の支援者がアクセスできる形にすることで「バーチャルなQ1環境」を提供

### 含意4: 都道府県別の「最適な連携体制の組み合わせ」が違う可能性

- 問13の連携体制参加率も都道府県によって大きく異なる可能性がある
- 知識AIが「あなたの地域では〇〇という連携体制が機能しやすい」という地域特性に応じた助言ができる設計が理想

## 追加分析：連携体制参加の「転換効率」の地域差

### 参加ネットワーク数とQ1率の関係（全国）

| 参加ネットワーク数 | Q1率 | n |
|---|---|---|
| 0体制 | 12.8% | 1,483 |
| 1体制 | 22.6% | 558 |
| 2体制 | 28.5% | 316 |
| 3体制 | 29.9% | 214 |
| 5体制以上 | 39.8% | 118 |

→ **参加体制数が増えるほどQ1率が上昇する。明確な用量反応関係。**

### 地域別の「参加→Q1転換効率」

| 地域 | 非参加者Q1率 | 参加者Q1率 | 転換効率（差） |
|---|---|---|---|
| 関東 | 14.1% | 32.8% | **+18.7%（最高）** |
| 中部 | 10.8% | 28.8% | +18.0% |
| 九州・沖縄 | 9.3% | 26.4% | +17.0% |
| 近畿 | 14.7% | 29.9% | +15.2% |
| 中国・四国 | 8.9% | 20.8% | +12.0%（最低） |
| **北海道・東北** | **18.8%** | 29.3% | +10.5% |

### 2つのメカニズムの発見

**メカニズム1: 北海道の「環境効果」**
北海道は非参加者のQ1率が18.8%（全国最高）。**連携体制に参加する前から** Q1が多い。
→ 「Q1支援者が周囲にいること」自体がロールモデルとなり、非参加者にも波及している。
→ **Q1密度が高い地域では「文化的伝播」でQ2→Q1転換が起きている。**

**メカニズム2: 中国・四国の「参加しても転換しない」問題**
中国・四国のQ2参加率はHW体制で26.5%（全国最高）。しかし転換効率は最低（+12.0%）。
→ **「参加しているだけでは不十分、参加の質が重要」という決定的証拠。**
→ 連携体制に参加しても、「事例を共有する・判断を学ぶ・実践に繋げる」プロセスが機能していない可能性。

### 知識AIへの含意（更新）

1. **中国・四国への優先介入**: 最も参加率が高いのに転換効率が最低 → AIが「参加の質」を高める支援を最優先
2. **北海道モデルの知識化**: 非参加者でも18.8%という高いQ1率の背景にある「Q1文化」をナレッジベース化
3. **「参加数 × 参加の質」の最適化**: 5体制以上参加でQ1率40%→ 量と質の両方を最大化する設計
