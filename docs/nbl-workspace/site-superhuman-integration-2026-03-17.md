# Site Superhuman Integration

更新日: 2026-03-17
Status: hidden review synthesis note

## Why this note exists

`site-superhuman-strategy-ja.md` は、`AIがすごい` ではなく `観測できる運用優位` をサイト体験としてどう見せるかを整理していた。

NBL にそのまま持ち込むと、個人最適や継続記憶の promise が強すぎる。
そのため、採用する原則と読み替える原則を切り分ける。

## Adopt as-is

- 神秘化より `見れば分かる差`
- 文章のうまさより `運用・実装・学習速度`
- `昨日より今日の方がよい` と外から感じられること
- 情報提供だけでなく、観察、提案、改善が一つの流れに見えること

## Translate for NBL

### `個別最適`

そのままは採らない。
NBL では `文脈に応じた routing と explanation` に読み替える。

### `継続記憶`

そのままは採らない。
NBL では `decision log / artifact / method の継続蓄積` に読み替える。

### `その場で組み替わるサイト`

そのままは採らない。
NBL では `問いに応じて入口が変わって見える構造` に読み替える。

## Hold for now

- 個人ごとの即時最適化 promise
- public site 上での強い継続記憶 promise
- 利用者ごとの履歴活用を前提にした強い personalization

これらは privacy、boundary、human review が十分固まるまでは public に出さない。

## What this changes in NBL

NBL の showcase は、`AIで作ったきれいなサイト` ではなく、次の3点が見えるサイトへ寄せる。

1. 更新が部品として残る
2. 改善理由が追える
3. 速さより境界が見える

## Immediate use

- `Showcase Direction Round` に `visible improvement` を追加する
- `Relaunch Public Home` に learning trail の断面を加える
- `snapshot automation` と public narrative を、将来は軽く接続する
