# Q2→Q1転換経路マップ：「意欲ある支援者」が実践者になるための知識設計

作成日: 2026-04-02
根拠: toku18 4象限分析 + 問12学習経路 + 問13連携体制 + narrative分析（n=3,053）

---

## なぜこの文書が必要か

### 「意欲があるのに動けない」が71.9%

toku18 n=3,053 の分析結果：
- **Q1（真の専門性実践者）**: 20.8%（n=635）
- **Q2（連携志向・制度的障壁型）**: 71.9%（n=2,196）
- Q3（機械的実施者）: 3.2%
- Q4（タテ割り完結型）: 4.1%

Q2の定義：
- 連携志向理念（問10）≥ 0.7（高い）
- 実施可能性（問11 自機関での連携活動実施）< 0.35（低い）

→ **理念はQ1と変わらない。問題は「環境と経験」。**

### Q1とQ2の語りの差（narrative分析）

| Q1（実践語り） | Q2（課題・認識語り） |
|---|---|
| 「就職後の支援の重要性を強調」 | 「就労支援の必要性を認識」 |
| 「地域連携を重視した支援」 | 「支援経験がほとんどない」 |
| 「地域連携体制の情報提供」 | 「知識や支援方法の必要性はすごく感じます」 |
| 「就労支援への前向きな姿勢」 | 「雇用側の偏見に言及」 |

Q1は「〜している」（実践の叙述）
Q2は「〜の必要性を感じる」「〜に影響される」（課題・認識の叙述）

**転換のシグナル**: 語りが「必要性語り」から「実践語り」に変わること。

          ↓ [3つの入口のいずれかから]

          ↓

  連携のための連絡を1件とる

## 転換の3つの入口（詳細）

### 入口A: 組織環境（上司・職場文化）の変化

**データ根拠**: Q1-Q2差 +0.131（全障壁要因で最大）
**対象**: C0b 完全孤立型（n=178: 上司スコア0.192）

**変化を起こすための知識**:

| 変化の種類 | 具体的アクション | 難易度 |
|---|---|---|
| 上司の理解を得る | 「就労支援連携の実績が出た報告書」を作成して見せる | 中 |
| 職場文化の醸成 | 就労支援成功事例をケース会議で共有する | 中 |
| 機関ミッションへの組込み | 管理職向けに「診療報酬と就労支援の接続」を提案する | 高 |
| 業績評価基準の変更 | 連携実績を評価指標に入れるよう提言する | 高 |

**最小実行可能アクション（上司の同意なしでできること）**:
- 患者から就労相談を受けたとき、外部機関へ「情報提供の電話1本」をかける
  → この1件の実績が上司へのレポートになる
  → 「就労支援の問い合わせが来ている」という事実が職場文化を変える起点になる

### 入口B: 学習経験の蓄積（推奨順序）

**データ根拠**: 問12 Q1-Q2差分析

| 学習源 | Q1-Q2差 | 学習タイプ | 優先度 |
|---|---|---|---|
| **実践経験の蓄積** | **+0.199** | 実践型 | 最高 |
| **所属機関の専門研修** | **+0.174** | 機関内 | 高 |
| **支援者間の情報交換** | **+0.159** | ピア学習 | 高 |
| **地域職業センターの助言** | **+0.154** | 実践的助言 | 高 |
| 職業リハビリ研修センター | +0.150 | 専門研修 | 中 |
| 民間ジョブコーチ研修 | +0.142 | 専門研修 | 中 |
| 図書・論文・文献 | +0.137 | 自己学習 | 補完 |
| Webリソース | +0.106 | 自己学習 | 補完 |

**所見**: 「実践経験（+0.199）> 機関内研修（+0.174）> ピア学習（+0.159）> 専門機関助言（+0.154）」の順で効果が大きい。Webリソース（+0.106）は最も差が小さい。

**Q2支援者への推奨学習順序**:

```
Step 1: 「支援者間の情報交換」から始める
  → 最も実行コストが低い（同僚・勉強会・オンライン）
  → 「他の支援者はどうやっているか」を知るだけで行動へのハードルが下がる

Step 2: 「地域職業センターの助言を求める」
  → 1ケース相談するだけで「専門機関との協働」経験になる
  → その助言が次の実践経験の材料になる

Step 3: 「実践経験の蓄積」
  → 最大の転換効果（+0.199）
  → ここは入口B・Cの両方が揃ってから最大化される

Step 4: 「機関内研修の充実」
  → Q1支援者は機関内研修が充実している環境にいる（機関ミッションとの連動）
  → Q2→Q1転換後に維持・強化する要因として機能する
```

### 入口C: 地域連携体制への参加（推奨順序）

**データ根拠**: 問13 Q1-Q2参加率差分析

| 連携体制 | Q1参加率 | Q2参加率 | Q1-Q2差 | Q2認知率 | 認知-参加ギャップ |
|---|---|---|---|---|---|
| 就労移行支援 | 31.6% | 14.6% | +17.0% | 32.2% | +17.6% |
| 就業・生活支援センター | 37.4% | 21.0% | +16.4% | 31.7% | +10.7% |
| HWチーム支援 | 38.5% | 23.2% | +15.3% | 23.5% | +0.3% |
| 職業センターケース会議 | 24.9% | 14.1% | +10.8% | 23.0% | +8.9% |
| 自立支援協議会 | 37.1% | 26.8% | +10.3% | 24.7% | — |
| 難病相談支援センター | 11.1% | 8.0% | +3.1% | 16.8% | +8.8% |

**重要所見**:

1. **就労移行支援**: Q2の32.2%が「知っている」のに参加率14.6%（ギャップ最大）
   → 「知っている」→「参加できる」の橋渡しが機能していない
   → 介入ポイント：初回参加の具体的な手順の提供

2. **就業・生活支援センター（なかぽつ）**: 全体で最高のQ1参加率（37.4%）
   → Q2→Q1転換に最も関連する連携体制
   → 参加すると「就業と生活の一体支援」の視点が身につく

3. **HWチーム支援**: Q2の認知率23.5%が低い（「知らない」ことが参加障壁）
   → 介入ポイント：「HWに専門の窓口がある」という認知の拡大

**Q2支援者への推奨参加順序**:

```
第1選択: 「就業・生活支援センター（なかぽつ）」
  → Q1参加率が全体最高（37.4%）
  → 「就業と生活を一体で見る」視点がQ2→Q1転換の核心に近い
  → 参加することで、医療機関の役割（生活面の医療フォロー）が明確になる

第2選択: 「HWチーム支援」
  → Q1参加率38.5%（最高水準）
  → HW中心のケース会議に参加すると「就労支援のチームプレー」を体験できる
  → 参加のハードルが比較的低い（HWに問い合わせれば招待される場合がある）

第3選択: 「就労移行支援事業所の連携」
  → Q1-Q2差が全体で最大（+17.0%）
  → 「就業準備段階から就職まで」を担う機関との協働経験が実践力を高める

第4選択: 「自立支援協議会」
  → Q2でも参加率が比較的高い（26.8%）
  → 「地域の就労支援体制を知る場」として機能（実践より情報収集フェーズ向け）
```

## Q2→Q1転換の総合ロードマップ

### フェーズ0: 認識転換（制度的孤立層 C0a向け）

**目標**: 「就労支援は自分の業務ではない」→「連携すれば自分も参加できる」

```
実行アクション:
  □ 就労意向のある患者に「ハローワーク・難病相談支援センター」を紹介する（1ケース）
  □ 地域の就業・生活支援センターに電話して「就労支援の流れ」を聞く
  □ 支援者間の情報交換（同僚・勉強会）で「就労支援に携わっている人」を見つける
```

**所要時間の目安**: 1〜3ヶ月
**転換シグナル**: 「連絡したことがある機関が1つ以上ある」

---

### フェーズ1: 最初の実践体験

**目標**: 「連絡した」→「ケース会議に参加した」→「連携した」

```
実行アクション:
  □ 1件のケースで就業・生活支援センターまたはHWと情報共有する
  □ 拡大ケース会議への招待があれば参加する
  □ 参加後に「何が起きたか」を同僚に話す（支援者間情報交換の実践）
```

**所要時間の目安**: 3〜6ヶ月
**転換シグナル**: 「連携した」経験が語れるようになる（語りの変化）

---

### フェーズ2: 専門性有効感の発生

**目標**: 「やった」→「効果があった」→「またやりたい」

```
転換メカニズム:
  ① 連携して患者が就職・定着した
     ↓
  ② 「自分の医療情報提供が役に立った」を実感
     ↓
  ③ 専門性有効感発生（問15③: Q1=0.727 vs Q2=0.530）
     ↓
  ④ やりがいの記述登場（問15④: やりがい語り Q1=0.317 vs Q2=0.190）
     ↓
  ⑤ 次のケースで積極的に連携を始める（正のフィードバックループ）
```

**所要時間の目安**: 6〜12ヶ月
**転換シグナル**: 「就労支援のやりがい」を語れる

---

### フェーズ3: Q1定着（真の専門性実践者）

**目標**: 「たまにやる」→「業務として定着する」

```
定着に必要な条件:
  □ 機関内研修が充実（問12②: Q1-Q2差 +0.174）
  □ 上司・職場文化が支持的（問14④: Q1-Q2差 +0.131）
  □ 複数の連携体制への参加（Q1平均2.22体制 vs Q2平均1.33体制）
  □ 実践経験の継続的蓄積（問12①: Q1-Q2差 +0.199: 最大）
```

## 「Q2→Q1転換を阻む壁」の突破策

### 壁1: 「上司が理解していない」（最大壁: +0.131）

**突破策**: 上司を変えようとするより、上司への報告材料を作る

```
証拠作りのアプローチ:
  1. 1件の連携ケースについて「連携した経緯・経過・結果」を記録する
  2. 「患者が就職できた」「定着している」という結果を上司に報告する
  3. 「このような連携を続けることで、患者の QOL向上・再診予防に繋がります」と説明する

→ 報告書が「業務化」の根拠資料になる
→ 管理職に「就労支援連携は業務に値する」と認識させる最小コスト介入
```

---

### 壁2: 「機関ミッションに就労支援がない」（+0.118）

**突破策**: 既存業務の拡張解釈でカバーできる部分を見つける

```
医療機関の既存業務と就労支援の接続:
  診療 → 就労への影響評価（職業的課題の把握）として読み替え可能
  リハビリテーション → 就業能力の維持・回復として連続性がある
  相談支援 → 生活課題の一部として就労相談を含める
  治療と仕事の両立支援 → 診療報酬加算の対象（支援計画書の作成）
```

---

### 壁3: 「連携の始め方がわからない」（Q2の主訴）

**突破策**: 最初の連絡の具体的スクリプト（institution-coordination-knowledge-2026-04-02.md参照）

```
最小行動:
  「〇〇（自機関名）の〇〇です。就労を希望している患者さんがいるのですが、
   貴機関でどのようなことができるか教えていただけますか？」

→ この電話1本でQ2支援者は「連携経験あり」のカテゴリに入る
→ 地域センター・なかぽつ・就労移行は、医療機関からの連絡を歓迎する
```

---

### 壁4: 「連携先が地域にない」（C0c: +0.182最高シグナル）

**突破策**: 遠隔・広域連携の活用

```
地域インフラ不在時の代替経路:
  ① 都道府県難病相談支援センター（広域対応可能）
  ② ハローワーク（オンライン相談・電話相談あり）
  ③ JEEDのオンライン職業評価（一部対応）
  ④ 在宅就業支援団体（テレワーク就業）
  ⑤ 当事者会・患者会（ピアサポートとしての就業情報）
```
