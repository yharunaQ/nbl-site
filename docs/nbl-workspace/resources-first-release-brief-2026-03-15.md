# Resources First Release Brief

更新日: 2026-03-18

## Resources Role

- 大量の素材を直置きせず、シリーズ単位で案内する
- 理解促進だけで終わらず、NBL の方法論や支援設計につながる入口にする

## Resources Should Include

- `見えない障害の理解` シリーズ
- 基礎図解 / 方法論図解
- 選抜した動画
- 主要レポート / 資料

## Resources Should Avoid

- WIP 素材の直置き
- 出典や時点が不明な制度断定
- 体験談を一般化する見せ方
- thought pieces の大量掲出

## First Release Collections

1. `見えない障害の理解`
2. Core frameworks and methods
3. Selected explainers
4. Reports and materials

## Editorial Rule

- `見えない障害の理解` は series として見せる
- 図解は method と understanding の 2 系統に分ける
- 動画は `public_now` の 5 本を最優先にする
- レポートは時点や法域の注記が必要
