# G6: IPS/Supported Employment 定量エビデンス

作成日: 2026-04-02
目的: 知識ネットワークの国際エビデンス基盤として、IPS/SEの定量的根拠を整備

---

## IPS（Individual Placement and Support）とは

### 定義と起源

IPS（個別就労支援）は1990年代にDeborah Becker・Robert Drake（米国）によって開発された、
精神疾患を持つ人を対象とした「援助付き雇用（Supported Employment）」の標準的モデル。

**8つのフィデリティ原則**:
1. 就労することが目標（「就労準備ができてから」を待たない）
2. 通常の競争的雇用のみを対象
3. 迅速な求職活動（サービス開始後30日以内）
4. 本人の希望を中心においた職業選択
5. 精神保健サービスと就労支援の統合（チームとして機能）
6. 個別化された職場開拓
7. 継続的な定着支援（時間制限なし）
8. 給付金カウンセリング（収入増加と福祉給付のバランス調整）

## 定量エビデンス（RCT・メタ分析）

### 主要RCT比較（IPS vs 従来型就労支援）

**「従来型」の定義**: 就労準備訓練型（stepwise/train-then-place）
- 施設内訓練 → 実習 → 競争的雇用 という段階的アプローチ
- 日本の就労移行支援はこれに近い設計

| 指標 | IPS群 | 対照群（従来型） | 効果量 |
|---|---|---|---|
| **競争的雇用獲得率** | **55〜65%** | **20〜25%** | **オッズ比3〜4** |
| 就業までの期間 | 短縮 | 6〜12ヶ月 | 有意差あり |
| 就業時間（週） | 多い | 少ない | 有意差あり |
| 就業継続期間 | 長い | 短い | 有意差あり |
| 生活の質（QOL） | 向上 | 維持 | 有意差あり |

**代表的メタ分析**（参照: Bond et al., 2012; Modini et al., 2016等）:
- IPS参加者の競争的雇用獲得は従来型の2〜3倍
- 効果は精神疾患の重症度と独立（重症例でも有効）
- 18ヶ月以上の長期フォローでも効果が維持される

---

### なぜIPSが効果的なのか（メカニズム）

**従来型の問題**:
```
就労準備訓練 → 訓練環境での評価 → 実際の職場では通用しない
               （訓練≠実働の壁）
```

**IPSの原則**:
```
希望する仕事への直接応募 → 実際の職場での適応支援 → 定着
（real job = real learning環境）
```

→ **「実践の中で学ぶ（実践経験の蓄積）」という原理は、支援者の学習（問12）と同構造。**

## 日本での文脈への適用

### 適用可能な要素

| IPS原則 | 日本での実装 | supports.mdとの対応 |
|---|---|---|
| 迅速な求職活動 | HW・就労移行での早期求職支援 | 企業へのアプローチ（連携）[-0.15] |
| 本人の希望中心 | 「個性強み興味把握（自前重視）」 | 個性強み興味把握[-0.08] |
| 精神保健×就労の統合 | 医療機関×なかぽつ×HWの連携 | 就労・生活一体相談（連携）[-0.08] |
| 継続的定着支援 | 就業・生活支援センターの就職後支援 | 就職後継続的職場・本人支援[-0.06] |
| 給付金カウンセリング | なかぽつでの生活相談 | 就労・生活一体相談（連携）[-0.08] |

→ **IPSの原則は、supports.mdの「有効介入」とほぼ一致している。日本のGLMデータがIPSを独立的に再発見した形。**

### 日本での制約・修正が必要な点

1. **「競争的雇用のみ」の原則**:
   - 就労継続A型・B型など「競争的でない雇用」も有意義な選択肢
   - 難病患者・重度障害者では段階的移行が現実的な場合も多い
   - → 「本人の希望と能力に応じた柔軟な就業形態」として修正適用

2. **「30日以内の迅速な求職」の原則**:
   - 日本の就労移行は原則2年間のプログラム
   - ただし、「訓練優先ではなく就業機会の早期探索」という精神は適用可能

3. **医療と就労支援の統合チーム**:
   - 日本では医療機関と就労支援機関が組織的に分離（→ C0問題の核心）
   - 連携体制（問13）がIPSの「統合チーム」の代替として機能する可能性

## IPS/SEと日本の知識ネットワークの接続設計

### 「IPSの原則」を「日本の連携体制マップ」に翻訳する

```
IPS8原則の日本語訳（Just Enough Translation）:

原則1「就労することが目標」
 → 「訓練してから」「状態が安定してから」を待つことへの警鐘
 → Q2支援者が陥りやすい「準備主義」への対抗知識

原則5「精神保健×就労の統合チーム」
 → 医療機関（C0）がQ1になるために最も重要な原則
 → なかぽつ・地域センター・HWとの「役割分担チーム」として実装

原則7「継続的定着支援（時間制限なし）」
 → supports.md「就職後継続的職場・本人支援（自前）[-0.06]」の根拠補強
 → 「就職で終わり」でなく「就業継続」まで責任を持つ設計

原則8「給付金カウンセリング」
 → 就労することで福祉給付が減額される「働き損問題」への対応
 → なかぽつ・相談支援事業所との連携で対応
```

## 知識ネットワークにおける位置づけ

### IPSエビデンスが担う役割

1. **Q2支援者への「実践の正当化」**: 「世界的に証拠がある方法」として連携型実践を正当化
2. **管理職への「投資対効果の論拠」**: IPS群の競争的雇用獲得率2〜3倍は、機関長への説明材料になる
3. **「訓練優先主義」への対抗知識**: Q4支援者（タテ割り完結型）や「就業準備が整ってから」という文化への対抗

### AIが活用するシナリオ

**シナリオ1: 「もっと訓練してから就職した方がいい」という支援者・機関への対応**
→ IPSの「place-then-train（就職してから学ぶ）」の効果量を提示
→ 「早期求職活動が実は成功率を上げる」というエビデンス

**シナリオ2: 難病患者への「定着支援の継続」の根拠**
→ IPS原則7（時間制限なし）の効果データ
→ supports.md「就職後継続的支援」との統合的説明

**シナリオ3: 医療機関への「チームアプローチ参加」の動機づけ**
→ IPS原則5（精神保健×就労の統合）の効果量
→ 「医療機関がチームに入ることで成功率が上がる」根拠
