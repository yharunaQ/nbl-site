# G4: 診療報酬と就労支援の接続フレーム

作成日: 2026-04-02
注記: 本文書は「考え方の整理」に特化。具体的な診療報酬点数・最新改定内容は別途厚生労働省の最新通知で確認が必要。
根拠: C0「資金・報酬基準」スコア0.361（全クラスタ最低）の構造的原因分析

---

## 問題の核心：医療機関の「就労支援をしない」合理的理由

### 診療報酬の仕組みと就労支援の「空白」

日本の医療機関は、提供した医療行為に対して診療報酬（点数）が支払われる。
診療報酬に含まれない行為は「収益を生まない業務」として機関内で評価されにくい。

**就労支援に関わる主要な問題構造**:

```
【現在の状況】
医師の診察 → 診療報酬あり（確実な収益）
PSWの相談支援 → 特定の加算で部分的にカバー
OTの機能訓練 → リハビリ報酬でカバー
「就業条件の評価・外部機関への情報提供」→ 報酬なし/曖昧

→ C0の「資金・報酬基準」スコア0.361 = この構造の直接反映
→ 「就労支援のために時間を使うと、その分の診察・治療を行えない」
```

### なぜC0（医療機関）だけが資金スコアで最低なのか

| クラスタ | 資金・報酬基準スコア | 機関種別 |
|---|---|---|
| C4（労働機関型） | 0.664 | ハローワーク・職業センター等 |
| C6（高能力型） | 0.554 | 複数機関混在 |
| **C0（医療・保健系）** | **0.361** | 病院・クリニック・保健所 |

労働機関（C4）の就労支援は「業務そのもの」。予算・職員配置が就労支援のために設計されている。
医療機関（C0）の就労支援は「業務外」または「付帯業務」として位置づけられている。

→ **この「就労支援の位置づけの差」が、機関ミッション・資金・報酬の格差として現れている。**

## 診療報酬が「就労支援」に部分的に接続されている領域

### 接続領域1: 精神科領域での就労支援

精神疾患・精神障害者の就労支援には一部の診療報酬が適用されている：

**精神科デイケア・デイナイトケア**:
- 「生活技能訓練（SST）」「就労支援プログラム」を含む多職種チームアプローチ
- 就労移行支援事業所との連携が「リワーク支援」として機能する事例あり

**精神科退院支援**:
- 精神科入院患者の地域移行・就労復帰に向けた退院支援計画
- 医療機関と就労支援機関の連携が報酬対象の一部として認められている

**考え方の含意**:
精神科では「治療の延長」として就労支援が報酬体系に部分的に組み込まれている。
これを難病・身体障害・その他の領域に拡張する制度設計が必要。

---

### 接続領域2: 「治療と仕事の両立支援」の加算（2016年～）

「治療就労両立支援」体制加算として、一部の医療機関が加算を算定できる体制整備が進められている。

**考え方の枠組み**:
- 患者が仕事を続けながら治療を受けられるよう、医療機関が「就業上の配慮に関する情報提供書」を作成する
- 雇用主・産業医への情報提供が診療報酬に接続されている

**限界**:
- 「就業している患者の治療継続支援」が対象
- 「就業していない患者を就業に繋げる支援」は対象外
- → 医療機関が支援できるのは「就業中の患者」であり、「就業を目指す患者」への積極的就労支援は報酬の外

**含意**:
「治療と仕事の両立支援」は最も整備が進んでいる接続点。
医療機関の就労支援参入の最初のステップとして活用しやすい。

---

### 接続領域3: 難病の「就労支援」との接点

難病医療費助成（指定難病）の認定・更新には定期的な医療機関受診が必要。
→ 難病患者は医療機関と「就業継続の話を定期的にできる関係」がある。

難病相談支援センター（難病法 §27）との連携:
- 法的には「難病患者の就労相談」は難病相談支援センターの業務
- 医療機関はセンターへの「紹介・情報提供」という形で接続できる
- この接続は「診療の付帯業務」として無理なく正当化できる

## 現在の報酬制度の「空白」が生む問題

### 空白の可視化

```
患者の就労ニーズのある医療機関訪問:

医師:      「就労については専門外」
             （診察時間を就労支援に使う報酬がない）
             ↓
PSW/MSW:   「就労支援は業務外」
             （就労支援連携の時間が業績評価に含まれない）
             ↓
患者:      「病院で相談したが、就労については何も教えてもらえなかった」
             ↓
就労支援機関: 「医療機関から情報がもらえないので支援の質が上がらない」
```

→ **この空白は個人の努力では埋まらない。制度設計の問題。**

### 現行制度下でできること（報酬なしでも可能な工夫）

1. **「就労支援は業務外」を「就労相談の紹介は業務内」へ読み替える**
   - 患者の相談に対して、専門機関への紹介書・情報提供書を作成する
   - これは「患者対応の延長」として現行業務内で正当化できる

2. **治療と仕事の両立支援加算の活用**
   - 就業中の患者に対して、「就業上の配慮に関する情報提供書」を作成する
   - 診療報酬算定の正当な手順に基づく

3. **外部連携は「患者同意を得た情報提供」として実施**
   - 法的に問題がない範囲で、外部機関へ医療情報を提供する
   - 患者の同意書を整備すれば診療の付帯業務として位置づけられる

## 診療報酬が就労支援を本格的にカバーするための方向性（政策含意）

### 必要な制度設計の方向（現状の空白の埋め方）

**方向A: 「就業能力評価」の診療報酬化**
- 現在: 医師・OT・PSWが就業能力の評価を行っても報酬なし
- 必要: 「就業条件の医療的評価」を診療報酬の対象項目として明確化
- 効果: 医療機関が就労支援に時間を使うインセンティブが生まれる

**方向B: 「外部就労支援機関との連携加算」の新設**
- 現在: 就労移行・なかぽつ・地域センターとの連携会議への参加は無報酬
- 必要: 多職種連携会議への医療機関参加を加算の対象に
- 効果: 医療機関がケース会議に積極的に参加するようになる

**方向C: 難病患者への「就労支援情報提供」の加算**
- 現在: 難病認定患者への就労支援情報提供は無報酬
- 必要: 定期外来時の「就労状況確認・支援機関紹介」を加算対象に
- 効果: 外来診察の中で就労支援が「当たり前の業務」になる
