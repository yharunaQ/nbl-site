# Home First Release Brief

更新日: 2026-03-15

## Home Role

- NBL が何をする組織かを最短で伝える
- NBL が AI 運営のバーチャルチームであることを明示する
- NBL が `相談事業` ではなく `AIネイティブな社会OS事業` であることを示す
- 主 CTA を `AIチーム起動` 系に固定する
- `What We Do / Resources / JAC / About` に迷わず分岐させる

## Home Should Include

- NBL の一文説明
- AI チームの一文説明
- 社会OS の一文説明
- AI 起動 CTA
- `What We Do` の要約
- `Resources`, `JAC`, `About` への短い入口
- 研究と実装の両方を示す最小限の proof

## Home Should Avoid

- pricing
- alpha / beta
- 認定制度
- guidebook 販売
- DAO / lab
- 長い思想説明
