## What Each Layer Does

### 1. Commercial Discovery Kit

- 相手に最初に何を見せるかを固定する
- `brief -> exclusions -> boundary -> call guide` の順を作る

### 2. Partner Discovery Ops Round

- 誰を相手にするかの target condition を固定する
- scorecard と stop rule を固定する

### 3. Partner Candidate Pipeline

- 実名候補の前に、A1 / A2 / B1 / C1 の slot を固定する
- network convenience で相手を選ばないための土台

### 4. Partner Sample Packet

- 匿名サンプルで、candidate input、conversation memo、ranking の埋まり方を確認する
- 実名候補投入前の rehearsal

### 5. Partner Dossier Kit

- live candidate を 1 枚 dossier で持つ
- 3-4 conversation ごとに founder-readable な round readout に閉じる
