## Core Takeaways

- 合理的配慮は `思いやり` ではなく、`仕事・情報・運用の設計` として捉える
- 雇用率は先に追う target というより、職場設計と雇用管理が機能した結果として現れる `結果指標`
- 企業が最初に取り組みやすい実務軸は `中途障害者の継続雇用` と `ニューロダイバーシティ`
- 盲点は `相談・開示しにくさ`。秘密保持、情報共有範囲、相談導線を設計しないと継続就労も雇用率安定も難しい
- `まず職場設計で改善できる領域を取る`。支援機関との連携は次の一手として組み込む
- 支援は `丸投げの代替` ではなく、職場設計を進めるための共同作業

## What This Changes In NBL Inbound

- 企業向け入口では、`合理的配慮 = 特別対応` より `合理的配慮 = 職場設計` を前面に出す
- 障害者雇用だけに閉じない入口でも、論旨の中心は `仕事設計・情報設計・運用設計`
- public で最初に見せる関心軸は次の 4 つ
  - 職場設計としての合理的配慮
  - 中途障害者の継続雇用
  - ニューロダイバーシティ
  - 相談・秘密保持・情報共有の設計

## What This Changes In JAC Posture

- JAC は `個別相談` より `条件つきの職場設計を考える method entry`
- guidebook は `すぐ買う商品` より `仕事設計の見直しを始める低摩擦の入口 asset`
- 有料化は、相談料より `継続利用 / private workspace / rate 超過` 側で設計する

## Guardrails

- 障害種別で固定的に人を説明しない
- 設計課題の例は出しても、個人差と条件差を省略しない
- 支援連携を最初から前提にしすぎず、企業の職場設計責任を曖昧にしない
- 雇用率だけを目的化せず、継続就労と設計品質の改善に結びつける

## Implementation Consequences

- `/for-enterprise` は `職場設計` の入口として調整する
- hidden review の `enterprise inbound` も同じ論旨へ寄せる
- 今後 public に戻す `What We Do` / `JAC` でも、この article framing を維持する
