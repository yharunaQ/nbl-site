## 2. 3層スタックの再定義

### 基本構造（維持）

| レイヤー | 対象 | 機能 |
|---|---|---|
| Layer A | 当事者・支援者 | 困難の構造化と具体的一手の設計 |
| Layer B | Q2支援者 | Q2→Q1転換の実践知マスタリー |
| Layer C | 管理職・機関長 | 組織診断と変革フレームワーク |

### Layer A の再定義（今回の最大更新）

Layer Aは「障害者向けAI相談」ではなく、**より広い射程を持つ仕事設計の実践知基盤**として再定義する。

**3段階の射程**:

1. **喫緊の課題（現在）**: 相談現場で就労の詰まりを仕事・環境・制度の設計課題として解く実践ツール
2. **中期目標（2〜3年）**: 障害者雇用からインクルーシブ雇用への転換を、理念でなく実践から積み上げる基盤
3. **長期目標（5年〜）**: AI・生産性向上時代において、役割が一部に集中する設計から多様な人が強みを発揮できる設計への移行を、現場の実践から準備する

この再定義は既存の27フレームの内容と完全に整合している。フレームの設計思想（「個人の問題」→「仕事・環境・支援・制度の設計課題」）が、そのままインクルーシブ設計の実践知になっている。

### Layer A と Layer B の関係（更新）

27フレームガイドブックは**Layer A・Layer B の共通知識基盤**として機能する。

| 使い方 | アクセスの視点 | 対象 |
|---|---|---|
| Layer A文脈 | 「自分に何が起きているか、どんな選択肢があるか」 | 当事者本人・家族 |
| Layer B文脈 | 「この状況でQ1支援者なら何をするか」 | 支援者（Q2→Q1転換） |

/jac/frames（27フレームガイドブック）は両レイヤーに横断するリソースとして設計する。

## 3. サイトアーキテクチャ（v3）

### サイトマップ

```
/                       ホーム（3ターゲット別分岐）
/jac                    JAC（当事者・支援者向け：Layer A）
  /jac/next               FCHMAベースAI相談UI（実装可能）
  /jac/frames             27フレームガイドブック（当事者向け読み方）
/knowledge              知識ネットワーク（支援者向け：Layer B）
  /knowledge/frames       27フレーム（支援者向け読み方・実践マッピング付き）
  /knowledge/practice     実践事例ライブラリ（Q1支援者の語り）
  /knowledge/network      地域連携体制ナビ（Q13データ可視化）
/for-managers           管理職・機関向け（Layer C）
/resources              リソース・啓発コンテンツ
/about                  NBLについて・3層スタック全体像
```

### /jac と /knowledge の27フレームの使い分け

同じ27フレームを異なる読者向けに提示する。コンテンツ本体は共通。

| パス | 提示方法 | 読者 |
|---|---|---|
| `/jac/frames` | 「あなたの困りごとはこのフレームで整理できる」 | 当事者本人・家族 |
| `/knowledge/frames` | 「この状況でどう動くか、Q1支援者の実践マップ」 | 支援者 |
