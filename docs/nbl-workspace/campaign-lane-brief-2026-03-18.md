# Campaign Lane Brief

更新日: 2026-03-18

## Holistic Positioning

- Scope of source:
  - Founder note: 公共広告キャンペーンとして、見えない障害、合理的配慮、多機関連携、相互作用モデルなどの難しい概念を、覚えやすい song / MV で伝えたい
  - Current published candidates in `content-inbox/youtube-links.md`:
    - `人が先`
    - `幕を上げよう`
  - Constraint:
    - MV まで仕上げる制作コストが高く、公開導線が MV completion 待ちで止まりやすい
- Covered lenses:
  - `difficulty_occurrence`
    - 見えない障害や働きづらさが、なぜ見えにくいのかを情景で伝えやすい
  - `difficulty_resolution`
    - 合理的配慮や多機関連携が、善意ではなく必要な設計であることを印象づけやすい
  - `support_need_formation`
    - 当事者、企業、支援者のそれぞれに、何を支えるべきかの感覚を形成する入口になりやすい
- Missing lenses:
  - `symptom_work_interaction`
    - song 単体では、仕事条件、環境条件、症状変動との相互作用を具体化しきれない
  - 1曲ごとの audience、中心概念、具体場面、companion explainer が未整理
  - 制度や支援境界の注記は、song 単体では担いにくい

## What is currently usable

- Usable now (with conditions):
  - `campaign lane` を、NBL の awareness asset として扱う
  - MV 完成を待たず、`song + still visual + short concept note` を最小公開単位にする
  - 1曲に複数概念を詰め込みすぎず、`1曲1場面1行動刺激` で設計する
  - 企業向け、当事者向け、支援者向けの audience を混ぜずに出し分ける
- Not yet usable:
  - song 単体を explainer や制度案内の代替にすること
  - 当事者経験を一つの感動物語に圧縮して見せること
  - MV 未完成のまま `public hero asset` として前面に出すこと

## Bias/Discrimination Risk

- Risk level: medium
- Risk factors:
  - 感情訴求が先行すると、当事者経験の一般化や inspiration 化が起きやすい
  - 1曲に複数概念を詰めすぎると、合理的配慮や相互作用モデルが slogan に縮みやすい
  - 企業向けに出す場合、具体的行動や boundary を companion note で補わないと誤読されやすい

## Additional information required

### Must-have questions

- その曲は誰に聞いてほしいか
- 1曲の中心概念は何か
- 想定する具体場面は何か
- companion に置ける still / lyric / short note があるか

### Nice-to-have questions

- 既存の cover art や画像素材の有無
- 曲尺、サビ文言、一文 CTA
- 公開済み YouTube の説明文をサイト向けに改稿できるか

## Provisional next action

- Minimal safe action now:
  1. `campaign lane` を inventory 上の独立 series として扱う
  2. 初回公開単位を `song + still visual + 120-200字 concept note + boundary note` に固定する
  3. `人が先` は `試験公開中` の位置づけを保ったまま audio-first pilot 候補にする
  4. `幕を上げよう` は創作 / campaign 枠として別管理し、初期サイトの主導線には混ぜない
- Re-evaluation trigger:
  - 3曲分の minimum package が揃う
  - 各曲に audience 指定と companion note が付く
  - `Resources` か別ページに置くかの公開導線が定義できる
