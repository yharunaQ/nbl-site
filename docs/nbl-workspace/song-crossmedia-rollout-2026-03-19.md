# Song Crossmedia Rollout

更新日: 2026-03-19

## Position

campaign song は、NBL の `awareness lane` として筋がある。  
ただし、song 単体を explainer や制度案内の代替にすると、誤解、一般化、感動消費が起きやすい。

なので、公開の基本単位は次の順で考える。

1. `song`
2. `still visual`
3. `short concept note`
4. `related infographic`
5. `related video` があれば補助で付ける

## Media Roles

### Song

- 情景を返す
- 1場面の印象を残す
- 行動刺激を 1 つだけ渡す

### Infographic

- 概念を固定する
- slogan 化を防ぐ
- `それは何を意味するか` を補う

### YouTube

- 背景説明を補う
- 企業読者や支援者に実務の骨格を渡す
- 制度や方法論の位置づけを言語化する

## Release Logic

### 1. 合理的配慮テーマ

- 最初に前に出しやすい
- すでに `public_now` の関連動画がある
- 企業、当事者、支援者にまたがっても誤解が少ない

この lane は `video-first + song-support` が基本。

関連 video:

- `合理的配慮2.0入門`
- `難病・慢性疾患のある社員を支えるマネジメント実践ガイド`
- `難病就労連携「全体マップ」活用セミナー`

### 2. 人が先 / 見えにくい困りごと

- song が強い
- ただし感動話化のリスクもある

この lane は `song-first + infographic required + optional video` が安全。

関連 video は補助線として使うが、song の後ろに置く。

### 3. 障害者雇用の質 / 構造更新

- 問題提起としては強い
- しかし song だけだと slogan に縮みやすい

この lane は `video-first` が基本。
song は補助線として後から出す。

### 4. インクルーシブ雇用 / 次の仕事観

- NBL らしさは強い
- ただし 2026-03-20 の流入向けには抽象度が高い

この lane は、初回公開の main CTA ではなく、resources や vision 補助線として育てる。

## March 20 Rule

- top page の main 導線には入れない
- まずは `What We Do`、`for-enterprise`、`Resources`、`JAC foundations` を主導線にする
- songs は `campaign lane` の内部整備を進め、3曲分の minimum package がそろった時点で比較公開を検討する

## First Candidate

最初に比較しやすいのは `合理的配慮テーマ 3曲`。

- `DE ・KI・RU ジョーケン`
- `コンディション・スイッチ`
- `配慮があれば働ける`

理由:

- 既存動画と接続しやすい
- infographic 候補が比較的つけやすい
- 企業流入にも当事者流入にも開きやすい

## Guardrail

- song に制度判断を代替させない
- 当事者経験を成功物語に圧縮しない
- ranking contest より `理解が深まったか` を重視する
- 公開時は `何を返せる song で、何を返せないか` を companion note に書く
