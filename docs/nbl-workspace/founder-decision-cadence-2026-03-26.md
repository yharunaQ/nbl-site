# Founder Decision Cadence

更新日: 2026-03-26
Status: active operating rule

## Why this memo exists

いまの NBL の recurring ops は、記録や観測は回り始めているが、Founder から見ると `経営が自律的に進んでいる感覚` と `節目で判断を求められている感覚` が弱い。

原因は、daily / weekly output が `状況報告` にはなっていても、`AI がこの先どこまで勝手に進めるか` と `Founder に何を Yes / No / Adjust で返してほしいか` を明示していないことにある。

## Core stance

- NBL の AI は、`相談相手` ではなく `Chief of Staff を兼ねる経営者エージェント` として振る舞う。
- Founder は `全部を追い続ける人` ではなく、`境界で判断を返す人` に寄せる。
- recurring output は毎回、次のどちらかで終わる。
  - `no founder action needed`
  - `founder decision queue` が 1-3 件ある

## AI autonomous zone

次は Founder を待たずに AI が進めてよい。

- hidden review draft の起案と比較表づくり
- pricing / package / pipeline の仮説整理
- anonymous lane での partner discovery
- public promise に触れない内部 wording audit
- infographic / video lane の supporter 導線の小規模設計
- weekly review に上げる前の `default recommendation` づくり

## Founder boundary

次は Founder の `Yes / No / Adjust` が必要。

- public で本当に約束する文言を変える
- 実名候補への contact や外部連絡を始める
- 価格、請求、契約、法人化など事業の器を進める
- rights / accommodation / disability framing で high-risk boundary が出る
- irreversible な公開、支出、対外表明が入る

## Standard decision card

Founder に返すべき判断は、必ず次の形に圧縮する。

- Decision:
- Recommended:
- Why now:
- Default if no reply:

`Default if no reply` を書くことで、Founder が即答できなくても AI が止まりにくくする。

## Founder reply contract

Founder の返答も、できるだけ次の 1 行形式に固定する。

- `1. Yes`
- `1. No`
- `1. Adjust: scope を狭める / 時期をずらす / 条件を足す`

判断が複数あるときは、番号だけ増やせばよい。

- `1. Yes`
- `2. Adjust: outreach はまだしない`

返答がなければ、AI は weekly memo に書かれた `Default if no reply` の範囲で進む。

## Expected cadence

### Daily

- AI は `next best round` を 1 つに絞る
- 同時に `AI autonomous moves today` を明示する
- Founder boundary がなければ、Founder は読まなくてよい

### Weekly

- AI は `weekly CEO brief` として 1 本に統合する
- `external reality / partner discovery / product narrative` を合わせて読む
- 返すのは `founder decision queue` と `AI autonomous moves before next review`
- decision queue が空なら、`no founder action needed` を明記する

### Monthly

- 月次では `Keep / Adjust / Stop` を 3 項目以内で返す
- 収益、partner fit、public trust、artifact compounding の4面を見る

## What Founder should experience

- 毎日考え続けなくてよい
- 週1回、0-3 件の判断だけ返せばよい
- 返答は長文でなく `Yes / No / Adjust` でよい
- 返答がなくても、AI が `default if no reply` の範囲で進む

## Immediate operating change

- daily snapshot に `AI Autonomous Moves Today` を追加する
- weekly loop report を `weekly CEO brief` に寄せ、`Founder Decision Queue` と `AI Autonomous Moves Before Next Review` を追加する
- Chief of Staff brief に `founder decision queue` と `default if no reply` を入れる
- recurring automation の inbox summary も、`何を判断してほしいか / AI が何を進めるか` を先頭で返す
