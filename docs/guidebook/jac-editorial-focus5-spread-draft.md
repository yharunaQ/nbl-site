# JAC ガイドブック 重点5章 見開きドラフト

更新日: 2026-03-07
状態: editorial-draft

## 使い方

- この文書は、重点5章を `出版物として読むための見開き` に再編集した下書きです。
- ここでは、冊子本文よりも `読者の疑問にどう答えるか` を優先して、導入文・見出し・図版の役割を先に固定します。
- 法政策差、地域支援体制、戻し先は落とさず、読者が迷いやすい順に並べ替えています。

---

## 1. 支援接続アーキテクチャ

### 見開きで答える問い

制度や支援機関がたくさんあるのに、なぜ必要な支援につながらないのか。いま、どこで止まっているのか。

### 左ページ: 導入コピー

支援につながりにくいとき、足りないのは制度名の知識だけではない。多くの場合、止まっているのは「次に誰が動くか」「どこまで進んでいるか」「いつ見直すか」という工程の見取り図である。  

相談先を増やすほど安心になるように見えて、実際には、同じ話を別の窓口で繰り返し、責任者が曖昧なまま時間だけが過ぎていくことが少なくない。支援接続の難しさは、制度の複雑さそのものよりも、窓口の順番、期限、役割分担が一枚で見えていないときに大きくなる。  

この章は、制度を覚えるための章ではなく、止まっている工程をほどき、次の一手を決めるための章である。

### 右ページ: 先に決めること

- まず特定するのは `使える制度` ではなく `いま止まっている工程`。
- 制度差がある論点は、法域と自治体条件を先に固定してから読む。
- 企業単独で抱えにくい論点は、JAC 提案と地域支援体制をセットで示す。
- 止まったときは、責任者と次回接点を再固定する。

### 図版ラフ

- 左上: `止まりやすい3地点`
  - 相談先が増えすぎている
  - 期限が誰にも見えていない
  - 次の一手の責任者が不明
- 右全面: `支援接続ルート図`
  - 本人
  - JAC
  - 企業
  - 地域支援者
  - 制度窓口
- 図版の主役は窓口名ではなく、工程、期限、責任者。

### キャプション案

「制度を知ること」と「支援につながること」は同じではない。止まりやすい地点を見つけ、次の一手を固定すると接続は動きやすくなる。

### Web への逆輸入

- カード冒頭に `いまどこで止まっているか` の選択肢を置く。
- 接続案の前に `工程の見える化` を出す。
- 地域支援オーケストレーション別ガイドへの導線は、本文末ではなく上部補助線に置く。

## 2. 実習採用ブリッジ

### 見開きで答える問い

実習ではうまく見えたのに、採用後に急に崩れるのはなぜか。何を橋渡しできていなかったのか。

### 左ページ: 導入コピー

実習が順調でも、採用後に運用が崩れることは珍しくない。実習では配慮されていた条件が、採用後の通常運用へ引き継がれず、評価だけが残って設計が消えてしまうからである。  

本来、実習で見るべきなのは「できたかどうか」だけではない。どの条件なら安定したか、どこで負荷が跳ねたか、不調になったとき誰がどう戻したか。その情報が採用後1か月の運用へ接続されて初めて、実習は橋になる。  

この章は、実習と本採用を別々の出来事として見るのではなく、同じ運用設計の前半と後半としてつなぎ直すための章である。

### 右ページ: 先に決めること

- 実習評価は `採用可否` だけでなく `採用後に持ち込む条件` として整理する。
- 採用後1から4週の負荷上限、担当者、不調時の戻し先を先に決める。
- 制度や実習枠の条件は法域前提で確認し、本文では橋渡しに必要な運用だけを前に出す。
- 地域支援者が入るなら、定着支援と再評価のタイミングを最初から組み込む。

### 図版ラフ

- 左ページ下: `実習で見えた条件`
  - 安定した業務
  - 負荷が跳ねた場面
  - 有効だった支援
- 右ページ上: `採用後4週間`
  - 第1週
  - 第2週
  - 第3週
  - 第4週
- 左右を線でつなぎ、どの条件が引き継がれ、どれが切れているかを可視化する。

### キャプション案

実習評価は点数ではなく、採用後の運用条件として引き継いで初めて役に立つ。

### Web への逆輸入

- `実習で確認済みか` と `採用後に引き継いだか` の2段チェックを追加する。
- カード上部に `初月で崩れやすい条件` を先に出す。

## 3. 相談運用ガバナンス

### 見開きで答える問い

相談窓口はあるはずなのに、なぜ調整がいつも遅れるのか。誰が受け止め、誰が次の一手を決めるのか。

### 左ページ: 導入コピー

相談の仕組みがあることと、相談が機能していることは違う。困りごとが表に出てから誰も動けないとき、足りないのは気づきや善意よりも、責任線と戻し先の設計である。  

現場では「相談してよい」と言われていても、誰に伝えれば業務設計が変わるのかが見えないまま、本人だけが様子を見る状態になりやすい。管理者、人事、支援者、外部支援の役割が重なったり抜けたりすると、相談はあるのに調整が遅れる。  

この章は、面談のマナーを整える章ではない。相談が遅れない仕組みを、責任線と時間の流れで設計するための章である。

### 右ページ: 先に決めること

- 相談の一次窓口と、次の一手を決める責任者を分けて見える化する。
- 健康情報や共有範囲は、配慮実装に必要な最小限へ絞る。
- 管理者だけで抱えない。外部支援へつなぐ条件を先に決める。
- 相談が形骸化したら、役割分担そのものを分解し直す。

### 図版ラフ

- 横向きタイムライン:
  - 現場で違和感が出る
  - 一次窓口が受ける
  - 業務変更の判断
  - 外部支援へ接続
  - 見直し
- 各地点に `誰が受ける / 誰が決める / どこへ戻す` を明記。
- 止まりやすい地点は赤、流れる地点は青。

### キャプション案

相談の量が増えても、誰が次の一手を決めるかが曖昧なら調整は進まない。

### Web への逆輸入

- 相談経路を文章だけでなくタイムラインで見せる。
- `誰が受けるか` と `誰が決めるか` を別表示にする。

## 4. 情報開示レイヤー設計

### 見開きで答える問い

どこまで伝えれば配慮につながり、どこからが伝えすぎになるのか。何を、誰に、何のために話すべきか。

### 左ページ: 導入コピー

情報開示は、するかしないかの二択ではない。配慮を実装するために必要な共有と、共有しなくてよい情報を分けて設計する作業である。  

共有が少なすぎれば必要な配慮が動かない。共有が多すぎれば、本人の不安や二次的な負担が大きくなる。難しさは、何を隠すかよりも、何のために誰へ伝えるのかを先に決めないまま話が始まってしまうところにある。  

この章は、「全部話す」「何も話さない」の間にある設計を作る章である。共有目的、共有相手、共有量、見直し時点を、最小共有の考え方で組み立てる。

### 右ページ: 先に決めること

- まず決めるのは `何を共有するか` ではなく `何のために共有するか`。
- 共有量は、配慮実装に必要な最小限で設計する。
- 共有先ごとに目的、記録責任、見直し時点を分ける。
- 開示量の判断は企業内だけで抱えず、支援体制とセットで考える。

### 図版ラフ

- 半透明3層レイヤー図:
  - 本人だけが持つ情報
  - 管理責任者が持つ情報
  - チーム共有する情報
- 各層に `共有目的` と `見直し時点` を小さく添える。
- 図版の主役は病名ではなく `共有目的`。

### キャプション案

情報開示の設計で大切なのは、どれだけ話すかよりも、何のためにどこまで共有するかを先に決めること。

### Web への逆輸入

- カードの入口を `共有目的` から始める。
- 共有先別の開示量は折りたたみで見せる。
- `最小共有` と `戻し先` を固定表示にする。

## 5. 悪化予兆ハンドリング

### 見開きで答える問い

悪化のサインが見えても、どの段階で誰が動けばよいのか。重くなる前に何を決めておけば戻せるのか。

### 左ページ: 導入コピー

不調への対応が遅れるとき、問題は「異変に気づけなかった」ことだけではない。小さな変化を、どの段階で、誰が、何に変えるかが決まっていないために、動けなくなることが多い。  

悪化は突然の出来事として語られやすいが、実際には、その前に小さなサインが出ていることが少なくない。連絡が遅れる、作業の立ち上がりが鈍る、休憩後も戻りにくい。そうした変化を「まだ大丈夫」と流しているうちに、調整は難しくなる。  

この章は、緊急対応マニュアルを作る章ではなく、初期サインから段階調整、再評価までの戻り道を先に持つための章である。

### 右ページ: 先に決めること

- `初期サイン` を観察できる言葉で置き換える。
- 段階ごとの負荷調整ルールを先に決める。
- 共有範囲は目的限定で決め、緊急時だけでなく再評価導線まで含める。
- 企業単独で担えないときは、地域支援者の再評価導線を最初から入れる。

### 図版ラフ

- 縦型メーター:
  - いつも通り
  - 小さな変化
  - 調整が必要
  - いったん止める
- 各段階に `誰が確認する / 何を変える / どこへ戻す` を配置。
- 下部に `再評価の戻り道` を矢印で表示。

### キャプション案

悪化対応で重要なのは、危機の場面だけではない。早い段階で戻し方を持っているかどうかが、離脱リスクを大きく変える。

### Web への逆輸入

- `初期サイン` をカード上部に固定表示する。
- 緊急対応は折りたたみ側へ送り、日常の段階調整を上に置く。
- 地域支援への戻し先を、補助線ではなく本文側に近づける。

---

## 共通メモ

- 5章とも、制度や支援機関そのものを主役にしない。
- 主役にするのは、読者が `どこで止まり、何を先に決めれば動けるか`。
- 冊子で確定した見出し順と図版の切り方は、Web ガイドへ順次逆輸入する。
