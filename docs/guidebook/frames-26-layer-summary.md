## 体調レイヤー（9フレーム）

### 1. 体調変動マネジメント（体調の波で日ごとの達成度がぶれやすい）
- 要約: 症状の波・疲労・回復遅延がある場合、同じ業務量でも日ごとの達成度が大きく変動しやすい。
- 障害者雇用との接続（多様性の例）: 内部障害 / 精神障害
- ポイント！（共通設計）: 業務量を週単位で平準化し、ピーク日を作らない / 90分ごとの短休憩を標準運用にする / 重要タスクを体調の安定時間帯へ再配置する
- ポイント！（個別調整）: 体調が崩れる直前の業務パターンは何か？ / 休憩で回復するのか、タスク変更が必要なのか？
- 生の声（仮想）: フルタイム労働が重なると、仕事のペースが急に崩れる。たまたま体調が落ち着いて動けたり、他の業務もこなせたりすると、ずるずると仕事が増える事が多く、結果、勤務時間や仕事内容が増えて負担になる

### 2. 治療スケジュール同期（通院予定と業務ピークが衝突しやすい）
- 要約: 受診予定と業務ピークが重なると、欠勤不安・有給消費不安・心理的負荷が重なり、就業継続の見通しが下がりやすい。
- 障害者雇用との接続（多様性の例）: 内部障害 / 肢体不自由
- ポイント！（共通設計）: 通院日を固定し、前後で業務負荷を調整する / 始業/終業時刻の可変枠を設定する / 引き継ぎテンプレートを作り、突発時の業務穴を最小化する
- ポイント！（個別調整）: 適用法域（JP/US/EUなど）と雇用区分は何か？ / 通院直後に難しくなる具体タスクは何か？
- 生の声（仮想）: フルタイム労働が重なると、仕事のペースが急に崩れる。通院や退院後の配慮（少しずつ職場復帰）

### 3. 回復時間バッファ設計（治療後の回復時間を確保できない）
- 要約: 定期治療の回復を無視して業務密度を維持すると、欠勤・再悪化・離脱が起きやすい。
- 障害者雇用との接続（多様性の例）: 内部障害
- ポイント！（共通設計）: 治療日を前提に業務密度を週単位で設計する / 不可業務帯を先に定義し、代替担当を確保する / 再悪化サイン時の勤務フォールバックを明文化する
- ポイント！（個別調整）: 不可業務帯と回復時間帯はどこか？ / 悪化兆候の判定基準は何か？
- 生の声（仮想）: 自分の障害や病気の適切な管理ができる自信が重なると、仕事のペースが急に崩れる。通院や身体の負担を先パイ・同僚は十分理解してくれていた上で、他の社員と区別する事なく接してくれたおかげで、仕事はもちろん社会勉強に大いになった

### 4. 勤務リズム整合（勤務帯の乱れで睡眠・服薬リズムが崩れやすい）
- 要約: 早出/遅出/夜勤や連続残業があると、睡眠・服薬・通院リズムが崩れやすく、症状悪化を引き起こしやすい。
- 障害者雇用との接続（多様性の例）: 内部障害 / 精神障害
- ポイント！（共通設計）: 固定シフト優先と残業上限の設定 / 夜勤・連続勤務の除外条件を明文化 / セルフチェック（睡眠/体調）を日次で記録
- ポイント！（個別調整）: どの勤務帯で悪化しやすいか？ / 夜勤・残業の代替手段はあるか？
- 生の声（仮想）: フルタイム労働が重なると、仕事のペースが急に崩れる。条件が合う日は安定して進められる

### 5. 復職ランプ設計（復職初期に負荷設定を誤ると再不調しやすい）
- 要約: 復職初期は「できる業務」と「継続できる業務」が一致しないことが多く、段階設計がないと再不調が起きやすい。
- 障害者雇用との接続（多様性の例）: 精神障害 / 内部障害 / 肢体不自由
- ポイント！（共通設計）: 復職初月は段階負荷（例: 60%→80%→100%）で設定する / 体調・勤務・業務進捗を同じシートで見える化する / 支援機関・産業保健との連携窓口を固定する
- ポイント！（個別調整）: 復職面談を週次で実施し、配慮を微調整する / 復職計画の合意がある
- 生の声（仮想）: フルタイム労働が重なると、仕事のペースが急に崩れる。採用は全て企業側に権限があり、どうしようもない

### 6. 悪化予兆ハンドリング（悪化兆候の見逃しで離脱リスクが上がる）
- 要約: 悪化兆候の定義や連絡手順がないと、対応が遅れて離脱・長期休職リスクが上がりやすい。
- 障害者雇用との接続（多様性の例）: 精神障害
- ポイント！（共通設計）: 段階的な負荷調整ルールを先に決める / 緊急時の連絡・共有範囲を目的限定で定義する
- ポイント！（個別調整）: 悪化兆候の観測項目を本人と合意する / 相談窓口と責任者が明確
- 生の声（仮想）: 精神的ストレスに適切に対処することが重なると、仕事のペースが急に崩れる。長期休みをとっているので、復帰できるか不安

### 7. 感覚環境チューニング（刺激過多で集中と持続が落ちやすい）
- 要約: 感覚刺激が強い環境では、集中低下と疲労増幅が重なり、業務継続性が下がることがある。
- 障害者雇用との接続（多様性の例）: 発達障害 / 精神障害 / 視覚障害 / 聴覚障害
- ポイント！（共通設計）: 静音席・照明調整・通知制御をセットで導入する / 作業ゾーン（集中/連絡）を分離する / 在宅/出社の使い分け基準を業務ごとに定義する
- ポイント！（個別調整）: どの刺激がどの時間帯に影響するか？ / 環境変更後に改善を測る指標は何か？
- 生の声（仮想）: 精神的ストレスに適切に対処することが重なると、仕事のペースが急に崩れる。条件が合う日は安定して進められる

### 8. 通勤負荷分散（通勤消耗で業務前にエネルギーが切れやすい）
- 要約: 混雑・移動時間・気温差が大きいと、業務開始前にエネルギーを消耗し、日中の集中維持が難しくなる。
- 障害者雇用との接続（多様性の例）: 肢体不自由 / 内部障害 / 精神障害
- ポイント！（共通設計）: 時差出勤と在宅勤務をタスク単位で使い分ける / 出社日は高協働タスク、在宅日は高集中タスクに再編する / 遠距離移動・連続出張の回避ルールを明文化する
- ポイント！（個別調整）: 通勤で最も消耗する要因（距離/混雑/乗換/気温）は何か？ / 出社必須タスクは本当に必須か？
- 生の声（仮想）: フルタイム労働が重なると、仕事のペースが急に崩れる。通勤緩和、時間軽減（軽減された分は中味として他で補充）

### 9. 移動動線最適化（移動動線の負荷で始業前疲労が高まる）
- 要約: 通勤や職場内動線に段差・遠回り・移動回数の多さがあると、始業時点で疲労が高まり作業継続が難しくなりやすい。
- 障害者雇用との接続（多様性の例）: 肢体不自由
- ポイント！（共通設計）: 通路・座席・機器配置を移動最小化で再設計する / 通勤混雑を避ける時差運用を固定する / 移動が多い業務を段階的に再配分する
- ポイント！（個別調整）: 最も消耗する移動区間はどこか？ / 動線変更で対応できる範囲と設備改修が必要な範囲は？
- 生の声（仮想）: 立った姿勢で仕事をすることが重なると、仕事のペースが急に崩れる。トイレや段差などの環境が整っていない

## 就職移行レイヤー（7フレーム）

### 1. 職務探索ナビゲーション（求人要件と自己理解が噛み合わない）
- 要約: 求人情報の読み解きと自己理解が噛み合わないと、応募前段階で迷いが長期化しやすい。
- 障害者雇用との接続（多様性の例）: 発達障害 / 知的障害 / 精神障害 / 高次脳機能障害 / 視覚障害
- ポイント！（共通設計）: 業務要件を「必須/調整可」に分解して適合度を可視化する / 強み・制約・必要配慮を1ページの探索シートに統合する / 週次で探索対象を3件に絞って検証する
- ポイント！（個別調整）: 希望職種の必須要件で最も障壁になる項目は何か？ / 調整可能条件として交渉できる余地はどこか？
- 生の声（仮想）: 障害と共存しての人生・生活の展望をもつことが重なると、仕事のペースが急に崩れる。条件が合う日は安定して進められる

### 2. 応募オペレーション設計（応募手順の曖昧さで機会損失が起こる）
- 要約: 応募手順が曖昧なままだと、連絡遅延や書類不備でチャンスを逃しやすい。
- 障害者雇用との接続（多様性の例）: 精神障害 / 発達障害 / 聴覚障害 / 視覚障害
- ポイント！（共通設計）: 応募手順を「連絡→書類→送付→追跡」の固定フロー化 / 履歴書・職務経歴書を役割別テンプレートで管理 / 応募後48時間以内のフォロー連絡を運用ルール化
- ポイント！（個別調整）: 今止まっている工程は連絡/書類/送付のどこか？ / 書類差戻しの主因は何か？
- 生の声（仮想）: 企業に対して自分をうまくアピールすることが重なると、仕事のペースが急に崩れる。なかなか本人が一人で活動出来なかったので親が一緒になって面接を受けさせて頂けたので助かりました

### 3. 面接合意形成デザイン（開示設計不足で配慮合意に失敗しやすい）
- 要約: 開示範囲の設計がないと、必要配慮が伝わらないか、過剰開示で不利益を招きやすい。
- 障害者雇用との接続（多様性の例）: 精神障害 / 発達障害 / 知的障害 / 聴覚障害
- ポイント！（共通設計）: 「伝える事実/伝えない情報」を二層で設計する / 配慮要望を業務影響ベースの短文で定型化する / 面接想定問答で3パターン練習する
- ポイント！（個別調整）: 面接で必ず伝えるべき業務影響は何か？ / 共有不要な情報はどこまでか？
- 生の声（仮想）: 自分の希望について周囲を説得して意思を通す自信が重なると、仕事のペースが急に崩れる。条件が合う日は安定して進められる

### 4. 学習パス接続（学習目標が広すぎ実務接続が弱い）
- 要約: 学習目標が広すぎると、実務に結びつかず離脱しやすい。
- 障害者雇用との接続（多様性の例）: 知的障害 / 発達障害 / 高次脳機能障害 / 肢体不自由
- ポイント！（共通設計）: 就業要件に直結するスキルを3段階で分解する / 訓練と実務タスクを週次で接続する / 達成指標を資格ではなく業務再現性で評価する
- ポイント！（個別調整）: 最優先で獲得すべきスキルは何か？ / 実務で検証できる課題は何か？
- 生の声（仮想）: 希望の仕事に就くための能力を身につけることが重なると、仕事のペースが急に崩れる。条件が合う日は安定して進められる

### 5. 実習採用ブリッジ（実習評価と採用後運用が接続していない）
- 要約: 実習時の評価軸と採用後の運用条件が繋がっていないと、定着に失敗しやすい。
- 障害者雇用との接続（多様性の例）: 肢体不自由 / 内部障害 / 精神障害 / 発達障害
- ポイント！（共通設計）: 実習段階で本採用後の評価指標を先に合意する / 就労初月の負荷上限を事前に設定する
- ポイント！（個別調整）: 引継ぎ責任者とフォロー面談を固定する / 実習評価が記録されている
- 生の声（仮想）: フルタイム労働が重なると、仕事のペースが急に崩れる。障害（高次脳機能障害）の理解をしていただき、定着にジョブコーチに支援をしてもらい、定着できている

### 6. 契約収入の安定設計（収入・契約・体調の整合が崩れやすい）
- 要約: 収入・契約条件・働き方の整合が取れないと、就労の意思決定が不安定になりやすい。
- 障害者雇用との接続（多様性の例）: 精神障害 / 内部障害 / 肢体不自由 / 知的障害
- ポイント！（共通設計）: 希望条件を必須/交渉可/受容可の3層に分ける / 収入見通しと体調維持可能な稼働量を同時に検証する / 初期契約期間の再評価タイミングを明確化する
- ポイント！（個別調整）: 最低限守るべき収入・契約条件は何か？ / 体調維持可能な稼働上限はどこか？
- 生の声（仮想）: 生活に十分な収入が重なると、仕事のペースが急に崩れる。条件が合う日は安定して進められる

### 7. 支援接続アーキテクチャ（支援情報の分散で接続が遅れる）
- 要約: 制度情報が散在していると、必要な支援へ接続できず就労移行が遅れやすい。
- 障害者雇用との接続（多様性の例）: 視覚障害 / 聴覚障害 / 肢体不自由 / 内部障害 / 知的障害 / 精神障害
- ポイント！（共通設計）: 支援機関・相談窓口・制度を1枚のルート図に統合する
- ポイント！（個別調整）: 相談目的ごとに窓口を固定し、重複相談を減らす / ケース会議で次アクションの責任者と期限を確定する
- 生の声（仮想）: 全般的に満足できる生活が重なると、仕事のペースが急に崩れる。条件が合う日は安定して進められる

## 職場運用レイヤー（10フレーム）

### 1. 会議処理容量設計（長時間会議で理解と疲労が同時に悪化）
- 要約: 長時間会議・即時応答・資料の同時読解が重なると、理解遅延と疲労蓄積が同時に起きやすい。
- 障害者雇用との接続（多様性の例）: 精神障害 / 発達障害 / 高次脳機能障害
- ポイント！（共通設計）: 会議を30分単位に分割し、論点を1テーマずつ固定する / 事前資料を前日配布し、当日は意思決定項目だけに集中する / 同期会議の一部を非同期コメントに置き換える
- ポイント！（個別調整）: 理解遅延は「どの会議」で最も起きやすいか？ / 会議後に落ちる業務（文章作成/判断/対人調整）は何か？
- 生の声（仮想）: 職場内で、会話や議論をすることが重なると、仕事のペースが急に崩れる。周りの人に、どういう状況にあるか、よく理解してもらうこと

### 2. 情報開示レイヤー設計（必要共有と過剰開示の境界が曖昧になりやすい）
- 要約: 必要配慮の実装には情報共有が必要だが、開示過多はプライバシー侵害リスクを高める。
- 障害者雇用との接続（多様性の例）: 精神障害 / 発達障害 / 内部障害
- ポイント！（共通設計）: 「共有する情報」と「共有しない情報」を二層で定義する / 職務遂行に必要な配慮情報だけをチーム共有する / 個人情報は管理責任者ルートで限定管理する
- ポイント！（個別調整）: 定期面談で開示範囲を見直す / 情報共有ポリシーと責任者が定義されている
- 生の声（仮想）: 企業に障害や病気を誤解されずうまく説明することが重なると、仕事のペースが急に崩れる。条件が合う日は安定して進められる

### 3. 相談運用ガバナンス（相談遅延で調整が後手になりやすい）
- 要約: 相談窓口が曖昧だと、困りごとが蓄積してから顕在化し、調整が後手になりやすい。
- 障害者雇用との接続（多様性の例）: 精神障害 / 発達障害 / 知的障害
- ポイント！（共通設計）: 現場→人事→支援機関のエスカレーション経路を明文化する
- ポイント！（個別調整）: 相談窓口を固定し、週次チェックインを定例化する / 本人申告が苦手でも拾える声かけ運用を設計する
- 生の声（仮想）: 仕事上の身分、仕事内容が安定して継続することが重なると、仕事のペースが急に崩れる。上司が、自分の買いもので”つかい”に出される

### 4. 対人応答負荷マネジメント（即時応答の連続で対人負荷が過密化）
- 要約: 即時応答が続く接客・対人場面では、情報処理負荷が高まり、伝達ミスや消耗が発生しやすい。
- 障害者雇用との接続（多様性の例）: 精神障害 / 発達障害 / 聴覚障害
- ポイント！（共通設計）: 接客タスクを難易度別に分け、段階配置する / 問い合わせ引継ぎの定型文・手順を整備する / 高密度対人タスクの後に低負荷タスクを挟む
