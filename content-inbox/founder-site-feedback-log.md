# Founder Site Feedback Log

NBL サイトを自分で見て気づいたことを、短く残す場所。

## Entries

- ここに追記

## Format

書き方:

- page:
- issue:
- desired effect:
- keep / change / drop:
- urgency:

## Example

例:

- page: `/review/relaunch-public-home`
- issue: 整っているが、showcase としての熱量が弱い
- desired effect: mechanism と artifact が先に見えるようにしたい
- keep / change / drop: keep taxonomy, change hero, drop equal card feeling
- urgency: 次ラウンドで対応
