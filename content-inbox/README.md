# content-inbox

公開候補の素材を最初に入れる場所。

入れてよいもの:

- メモ
- 原稿下書き
- PDF
- 画像
- 参考リンク
- まだ荒い構想

ルール:

- 完成していなくてよい
- public 前提で書けていなくてよい
- 1 ファイル 1 テーマを基本にする
- ファイル名は、見ただけで中身が分かるようにする

Founder が使う補助ファイル:

- `founder-new-content-log.md`
  新しい素材の意図を短く残す
- `founder-site-feedback-log.md`
  サイトを見て気づいたことを短く残す

次の流れ:

1. `content-inbox` に入れる
2. review 対象を `content-review` に移す
3. 承認されたものを `content-approved` に移す
4. 今は出さないものを `content-hold` に移す
