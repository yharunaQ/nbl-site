10作品シリーズの共通の画風で。

プロの漫画家として、以下の仕様書により、コミック風の４コマ漫画（縦長レイアウト）を制作して。
⸻
仕様書①「初出勤なのに、頭の中はトイレマップ」

1. タイトル（仮）

「初出勤とトイレマップ」

2. 目的・伝えたいこと
	•	IBD当事者にとって、新しい職場でまず気になるのは「人」より「トイレの場所」という現実。
	•	「いつでもトイレに行けるかどうか」が安心感に直結していることを伝えたい。

3. トーン・雰囲気
	•	ゆるコミックエッセイ風。
	•	明るい絵柄だが、さくらの不安はちょっとだけ表情でにじませる。

4. 登場人物
	•	佐藤さくら（主人公）
	•	部長（職場案内をしてくれる）

5. 舞台設定
	•	新しい会社のオフィスビル。
	•	エントランス → フロア案内図 → オフィス内の通路や会議室。

6. コマ割り・内容

1コマ目
	•	シーン：ビルの前で、さくらがスーツ姿で立っている。
	•	構図：ビルを見上げるさくらのバストアップ〜全身。
	•	セリフ・テキスト：
	•	さくら（心の声）「今日から新しい職場…！がんばらなきゃ！」
	•	表情・雰囲気：
	•	不安もあるが、キリッと前を向いている。

2コマ目
	•	シーン：ビルのフロア案内板を見ているさくら。
	•	構図：案内板の前。
	•	「○階：総務部」「○階：営業部」などの文字に混じって「トイレ」のアイコンが強調されている。
	•	セリフ・テキスト：
	•	さくら（心の声）「ええと…総務は…会議室は…」
	•	同じコマの中で、頭の中のモノローグ吹き出し：
「トイレは…？トイレどこ…？」
	•	表情・雰囲気：
	•	目線は真剣、少し焦っている。

3コマ目
	•	シーン：部長がオフィス内を案内している。
	•	「ここが総務ね」「こっちが会議室」など。
	•	構図：
	•	手前に部長、後ろを歩くさくら。
	•	さくらの頭の上に小さめのイメージ図で、フロアマップ＋トイレマークがどんどん描き加えられていく感じ。
	•	セリフ・テキスト：
	•	部長「ここが休憩スペースで〜」
	•	さくら（心の声）「休憩室の近くにトイレ…ナイス…！」
	•	表情・雰囲気：
	•	部長は普通に案内。
	•	さくらはうなずきながらも、実は別のこと（トイレ位置）に集中している目。

4コマ目
	•	シーン：さくらの顔アップ＋頭の中に完成したトイレマップ。
	•	構図：4コマ目はオチとして、さくらの表情と頭の中の図がメイン。
	•	セリフ・テキスト：
	•	ナレーション（モノローグ）
「私が一番最初に覚えるのは、
　　人の名前じゃなくて“トイレの場所”です。」
	•	表情・雰囲気：
	•	少し自嘲気味に苦笑しているさくら。
	•	マップには★マークでトイレが強調されている。

7. 備考・NG
	•	トイレの描写はアイコンやマーク程度で、直接的な「汚れ」の描写はなし。
	•	シリアスになりすぎず、「あ〜そうか…」とクスッとしながら気づけるトーンで。

仕様書②「会議中に何度も席を立つ人」

1. タイトル（仮）

「会議室とトイレの往復」

2. 目的・伝えたいこと
	•	会議中に何度も席を立つ人＝サボり、ではないこと。
	•	IBDでは、急な腹痛・下痢に対応せざるをえない状況がある。

3. トーン
	•	ちょっと切ないけど、重くなりすぎない。

4. 登場人物
	•	佐藤さくら
	•	同僚：田中（30代男性）
	•	他の会議メンバー数名（顔の描き分けはおまかせ）

5. 舞台設定
	•	社内会議室。テーブルとホワイトボード。

6. コマ割り

1コマ目
	•	シーン：会議中。さくらが立ち上がる。
	•	構図：テーブルを囲む数人。さくらが席を立ち、ドアの方へ。
	•	セリフ：
	•	さくら「すみません、ちょっと失礼します…」
	•	表情：
	•	さくらは申し訳なさそうな顔。

2コマ目
	•	シーン：さくらが出て行った後、残った同僚たちがヒソヒソ。
	•	構図：さくらの席が空いているのが分かる。田中と別の同僚のアップ。
	•	セリフ：
	•	同僚A「また抜けたよ」
	•	田中「会議中に何回トイレ行くんだろ…」
	•	同僚B（小声）「やる気ないのかなぁ」
	•	表情：
	•	田中たちは軽い感じで言っていて、悪意がそこまで強くない日常の無理解。

3コマ目
	•	シーン：トイレの個室内。さくらがしゃがんでお腹を押さえている。
	•	構図：上半身中心（便器は直接見せなくてOK。ドアやマークで場所が分かる程度）。
	•	セリフ：
	•	さくら（心の声）
「サボりたいわけじゃないのに…。」
「お腹だけはコントロールできない…。」
	•	表情：
	•	苦しそう＋少し涙目。

4コマ目
	•	シーン：ナレーション＋イメージカット。
	•	会議室のドアとトイレのドアが並んで見える構図など。
	•	セリフ・テキスト：
	•	ナレーション
「“トイレに自由に行ける職場じゃないと働けない”人もいます。」
	•	表情：
	•	キャラは小さくてもOK。さくらが遠目に小さく映っていれば十分。

7. 備考
	•	トイレ内の描写は清潔なイメージで。
	•	胃腸の「グルグル」など、擬音はコミカルすぎない程度にワンポイントならOK。

仕様書③「通勤ラッシュ vs お腹」

1. タイトル（仮）

「満員電車とお腹のタイミング」

2. 目的
	•	IBDでは、仕事より「通勤」が最大のハードルになることが多いという事実を伝える。

3. トーン
	•	日常の一コマとして描きつつ、最後は「遅刻＝だらしないとは限らない」気づきにつなげる。

4. 登場人物
	•	佐藤さくら
	•	通勤客たち（モブ）

5. 舞台設定
	•	朝の駅ホーム、満員電車、駅のトイレ。

6. コマ割り

1コマ目
	•	シーン：朝のホーム。満員電車のドアが開く。
	•	構図：ギュウギュウ詰めの車内が見え、さくらがホームで深呼吸している。
	•	セリフ：
	•	さくら（心の声）「今日こそ…ちゃんと乗るぞ…！」
	•	表情：
	•	決意＋不安。

2コマ目
	•	シーン：電車に乗り込もうと一歩踏み出した瞬間、腹痛。
	•	構図：さくらの顔アップ＋お腹のあたりに「キュルル…」的な軽い擬音。
	•	セリフ：
	•	さくら（心の声）「…やば…お腹が…！」
	•	表情：
	•	顔が青ざめ、冷や汗。

3コマ目
	•	シーン：電車には乗らず、ホーム上の「トイレ→」の看板の方へダッシュしていくさくら。
	•	構図：背中のカット。電車のドアが「閉」になりつつある。
	•	セリフ・テキスト：
	•	なしでも可。もしくは小さく
	•	車内アナウンス吹き出し：「ドアが閉まります」
	•	表情：
	•	後ろ姿だが、必死感が伝わるように。

4コマ目
	•	シーン：ホームに残ったさくら＋遠ざかる電車、時計のカット。
	•	セリフ・テキスト：
	•	ナレーション
「“遅刻グセ”の前に、
　　“トイレとの戦い”がある人もいます。」
	•	表情：
	•	さくらは肩で息をしながら、少し落ち込んだ顔。

7. 備考
	•	満員電車のしんどさは「人の密度」で表現。
	•	顔のアップはさくら中心で、モブは描き込み少なめでOK。

仕様書④「飲み会のお誘いLINE」

1. タイトル（仮）

「行きたいけど、行けない夜」

2. 目的
	•	食事・お酒がからむ場に参加しづらいこと、でも「本当は行きたい」気持ちを描きたい。

3. トーン
	•	しっとりめ。ただし暗くしすぎず、共感を呼ぶ感じ。

4. 登場人物
	•	佐藤さくら
	•	友人ミキ（LINE上＆ラストで少し登場でもOK）
	•	他の友達（LINE上の名前だけ）

5. 舞台設定
	•	さくらの自宅の部屋（夜）
	•	スマホ画面
	•	最後のコマで、居酒屋のイメージを小さく出してもOK

6. コマ割り

1コマ目
	•	シーン：さくらが自宅でスマホを見ている。
	•	構図：スマホ画面が見えるような構図。
	•	セリフ・テキスト（スマホ画面）：
	•	グループLINE
	•	「今日久しぶりに飲み行かない？」
	•	「行く行く〜！」
	•	表情：
	•	さくらは「いいなあ」と少し嬉しそう＋迷っている顔。

2コマ目
	•	シーン：頭の中のイメージ。
	•	居酒屋の料理（揚げ物・お酒）が並ぶテーブル＋トイレマーク。
	•	セリフ・テキスト：
	•	さくら（心の声）
「油ものとお酒はお腹が…」
「長時間トイレが遠い場所も不安…」
	•	表情：
	•	現実のさくらは眉を下げて困った顔。

3コマ目
	•	シーン：さくらがスマホに返信している。
	•	セリフ・テキスト（スマホ画面）：
	•	さくら「ごめん、今日は用事があって…また今度行くね！」
	•	友人の吹き出し（小さく）「え〜さくらまた〜？」「ノリ悪いな〜」
	•	表情：
	•	さくらは申し訳なさそうな笑顔。

4コマ目
	•	シーン：さくらが一人でテーブルにおかゆ（やさしい食事）を置いている。
	•	構図：自宅の小さなテーブル。テレビには居酒屋のCMくらいでも良い。
	•	セリフ・テキスト：
	•	さくら（小さな吹き出し）「本当は行きたくないわけじゃないんだよ…」
	•	表情：
	•	少しさみしそうだが、諦めきってない程度の表情。

7. 備考
	•	食事の描写はおいしそうに。ただし、主人公にとっては「お腹が心配」なもの、という対比が分かると良い。

仕様書⑤「“元気そうなのに”の一言」

1. タイトル（仮）

「元気そう、って言われるけど」

2. 目的
	•	見た目では分からない病気であること。
	•	「元気そうじゃん！」という何気ない一言が、時に苦しいことを伝えたい。

3. トーン
	•	少ししんみり。ただし説教くさくしない。

4. 登場人物
	•	佐藤さくら
	•	同僚A：田中（男性）
	•	同僚B（女性：さくらと別人であることが分かりやすい外見）

5. 舞台
	•	オフィスの休憩スペースやデスク周り。

6. コマ割り

1コマ目
	•	シーン：オフィスで雑談している。
	•	構図：立ち話している同僚たち。
	•	セリフ：
	•	同僚A「さくらさん、病気って聞いたけど大丈夫？」
	•	同僚の表情：
	•	心配しているような顔。

2コマ目
	•	シーン：続けて同僚が笑顔で。
	•	セリフ：
	•	同僚A「でも、元気そうじゃん！」
	•	同僚B「そうそう、全然そうは見えないよ〜」
	•	表情：
	•	さくらは一瞬、おっと困った顔→すぐ笑顔で合わせる。

3コマ目
	•	シーン：さくらの顔アップ（心の声コマ）。
	•	セリフ：
	•	さくら（心の声）
「“元気そう”って、
　　“つらくない”って意味じゃないんだけどな…」
	•	表情：
	•	無理して笑っている、自分でもそれに気づいているような顔。

4コマ目
	•	シーン：ナレーション＋さくらがデスクに向き直り、そっとお腹を押さえている。
	•	セリフ・テキスト：
	•	ナレーション
「見た目には出ない病気もある。
　　“元気そう”は、ときどき刃になる。」
	•	表情：
	•	さくらは小さくため息。

7. 備考
	•	同僚は「悪者」になりすぎないように、悪気のない感じで。
	•	読んだ人が「今度から言い方少し気をつけようかな」と思う程度の柔らかさ。
