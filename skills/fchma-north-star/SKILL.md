# Preserve The North Star

## Read First

Read these files before making product-shaping decisions:

- `../../AGENTS.md`
- `../../PLANS.md`
- `../../docs/nbl-workspace/fchma-consultation-os-redesign-2026-03-30.md`

## Re-anchor The Task

State in one sentence how the task strengthens at least one of these assets:

- case-centered workflow
- narrative structure
- ICF-based structural reasoning
- human review and edits
- intervention-outcome links
- pattern library growth
- auditability
- provider-agnostic AI integration

If the task does not strengthen one of these assets, narrow it or reframe it.

## Reject Drift

Stop and redirect if the solution starts collapsing into:

- a chat-first product
- an FAQ or search-first product
- a disease-to-accommodation lookup
- static form management without structural reasoning
- AI auto-judgment without human review

## Prefer This Core Loop

Prefer decisions that reinforce this loop:

1. case intake
2. structural analysis
3. human review
4. intervention planning
5. feedback recording
6. learning and pattern update

## Make Decisions Visible

When a decision changes product meaning, update one of:

- `../../AGENTS.md`
- `../../PLANS.md`
- `../../docs/nbl-workspace/fchma-consultation-os-redesign-2026-03-30.md`

Do not leave product-shaping decisions only in chat.
