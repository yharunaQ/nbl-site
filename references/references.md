# JACの知識基盤についての整理

JACの専門的知識は、「references」フォルダにある知識をICF（国際生活機能分類）の相互作用モデルにより、総合的な相互作用として捉えて整理したものである。
○就労困難性の相互作用の意味合い
1：特定の病気や機能障害によって就労困難性が発生しやすくなるが、仕事内容や職場配慮等、本人特性・スキルによって、問題の発生（経験）状況は影響される。
2：特定の病気や機能障害では就労困難性の問題の解決は困難となるが、仕事内容や職場配慮等、支援活用、本人特性・スキルによって、問題解決状況は影響される。
3：病気や障害の症状悪化の原因は、病気等の特性だけでなく、職場環境や仕事内容、働き方の影響も大きい。
4:障害者や難病患者本人が必要だと考える支援内容には、病気や経験している就労困難状況、本人特性が影響する。

「references」フォルダには次のデータがある。
