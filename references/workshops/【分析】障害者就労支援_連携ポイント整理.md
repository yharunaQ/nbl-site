# 障害者就労支援における多職種連携 — 成功・失敗ポイント整理

> 対象資料：広島・紋別・福岡・大分・目黒・全重協・難病相談センター・名古屋ワークショップ（計8回）のグループワーク・マインドマップ  
> 分析日：2026-03-31

---

## 分析の方針（第一原理）

**根本目的**：「障害のある人が、自分に合った仕事に就き、長く働き続けられること」

この目的を達成するために、以下の3軸で整理する。

1. **フェーズ軸**：就労の局面・タイミングごとに必要な連携を特定する  
2. **関係者軸**：各関係者の「得意（強み）」と「苦手（弱み・死角）」を明確にする  
3. **失敗モード軸**：どこで何が欠けると失敗するかを逆算的に抽出する

---

## 1. 登場する関係者と強み・弱み

| 関係者 | 主な強み | 主な弱み・死角 |
|--------|---------|--------------|
| **本人（当事者）** | 自身のニーズを一番知っている。就労意欲が原動力 | 自己理解が不十分な場合がある。SOSを出しにくい。病気受容に時間がかかる |
| **家族** | 日常生活の変化を最も早く察知できる。情緒的支え | 「我が子には無理」という過保護・諦め。支援制度の情報が乏しい |
| **企業・雇用主** | 実際の仕事創出。職場内の日常的サポート。業務の実態を知る | 障害特性・支援制度の知識不足。企業だけに負担が集中しやすい |
| **就労移行支援事業所** | 障害特性の専門知識。マッチング支援。継続的関係 | ビジネス知識が限られる場合がある。マンパワー不足 |
| **ハローワーク** | 求人情報集約。法制度。幅広い雇用者ネットワーク | 就職後のフォローが手薄になりやすい |
| **医療機関（主治医）** | 診断・病状管理。就労可否の専門的判断。最早期から関与 | 就労支援制度・福祉の知識が乏しい場合がある。他機関への「つなぎ役」になりにくい |
| **難病相談センター** | 難病特性への知識。医療と就労の橋渡し。精神的サポート | 就労支援リソースが限られる。キャパシティが小さい |
| **特別支援学校・大学** | 長期間（4年以上）の関係性。早期発見の機会。教育基盤 | 卒業後に情報が途切れる。個人情報保護で次機関への引き継ぎが困難 |
| **行政・自治体** | 助成金・制度。交通支援。地域ネットワーク整備 | 画一的・縦割りになりやすい。個別対応の柔軟性に欠ける場合がある |
| **相談支援専門員・ケアマネ** | 生活全体のコーディネート。関係機関の橋渡し | 就労の専門性は高くない場合がある |
| **ジョブコーチ** | 職場内での実地サポート。企業と本人の調整 | 人材不足。派遣制度の周知が不十分 |
| **当事者同士・患者会** | ピアサポート。リアルな成功事例の共有。精神的安心感 | 組織化・継続運営が難しい |

## 2. フェーズ別 連携ポイント

### Phase 0：超早期（学校在学中・診断直後）
**目的**：就労可能性の種まきと情報の空白を防ぐ

**成功のポイント**
- 特別支援学校・大学は**入学時から**障害情報を把握し、キャリア教育を開始する（「就活段階では遅い」）
- **グレーゾーン（未診断・未受診）学生**を1〜2年次に早期把握し、継続的に関わる
- 医師・主治医が診断時に「まず辞めないで」「支援がある」と**一言添える**だけで、その後の相談行動が大きく変わる
- 高校・大学と次のフェーズの支援機関との**情報引き継ぎ経路**を事前に整備する（高大連携、学校→就労移行支援）

**失敗を避けるポイント**
- 学校・医療・福祉それぞれが「自分の担当ではない」と情報を抱え込まない
- 本人・家族が「就労は無理」と思い込む前に、成功事例を見せる機会を作る
- 手帳取得の検討は就活直前ではなく、**時間的余裕のある時期**に行う

---

### Phase 1：就労準備（就活前）
**目的**：本人の自己理解と社会ルールの習得

**成功のポイント**
- **本人の強み・弱み・配慮事項の言語化**（自己理解→自己開示の練習）：支援機関がツール（チェックシート等）を使って整理
- **職場体験・インターンシップの義務化・普及**：知ることが就労意欲の最大の起爆剤
- ビジネスマナー・報連相・コミュニケーションの訓練（特に対人スキルが課題の場合）
- 企業側からも「あるとよいスキル」を事前に開示し、求人内容を可視化する
- 当事者が「自分に合う仕事」のイメージを持てるよう、多様な職種・業種を体験させる

**失敗を避けるポイント**
- 支援機関が「何でも手伝う」姿勢で本人の自立を損なわない
- 家族の意向と本人の希望のズレを放置しない（家族と本人を別々にアセスメント）
- 訓練・実習が「就職とは無関係な別物」にならないよう、実習先企業への就職経路も設計する

---

### Phase 2：マッチング・就職活動
**目的**：本人と仕事の最適な組み合わせを実現する

**成功のポイント**
- **コーディネーター（調整役）の存在**：ハローワーク、就労移行、企業の三者をつなぐ中核人材
- **マッチングチェックシート等の共通ツール**：本人の特性・希望と企業のニーズを両面から整理
- 企業側の「どんな人材が必要か」の把握と、本人の「どんな配慮が必要か」の開示を**同時進行**させる
- 職場見学・実習を「就職前提でない体験」として設計し、企業の心理的ハードルを下げる
- 求人情報は複数機関に分散せず、**集約・共有できる仕組み**を作る

**失敗を避けるポイント**
- 「どの機関が中核になるか」が曖昧なまま複数機関が動くと、連携が空回りする（責任の所在を明確に）
- 障害者枠の求人だけに限定せず、一般枠での配慮雇用の可能性も探る
- マッチングが「書類上の適合」にとどまらないよう、実際の職場環境を必ず確認する

---

### Phase 3：採用直後・職場定着の初期（最初の3〜6ヶ月）
**目的**：職場環境を整え、離職リスクを最小化する

**成功のポイント**

**企業内の整備**
- **業務の細分化と切り出し**：障害特性に合った業務を既存業務から再設計する
- **視覚化されたマニュアル**（文字だけでなくイラスト・写真・動画）
- **担当者の明確化**：本人の状態変化を把握する担当者、休んだ時の対応者、医療連絡窓口を事前に決める
- **バリアフリー・合理的配慮**の具体的整備（筆談ボード、インターホン、設備改修への助成金活用）
- 社内横断的なサポートグループ設置（一人のジョブコーチへの集中を避ける）

**外部との連携**
- **就職後も支援機関が関与し続ける**：「つないで終わり」にしない。定期的な職場訪問
- **医療機関—企業—支援機関の三角連携**：主治医への情報共有、服薬管理の配慮、通院しやすい配置
- 家族への情報共有と、家族が変化に気づいたときの連絡経路を確立

**失敗を避けるポイント**
- 採用後のサポートを企業だけに任せない（「企業任せ」は最大の失敗要因）
- 「問題が起きてから相談」ではなく、問題前から定期面談を仕組み化する
- 本人が「相談していい」「弱音を言っていい」と思える関係性を最初に作る

---

### Phase 4：中長期的定着・継続
**目的**：変化する状況に対応しながら就労を維持する

**成功のポイント**
- **定期面談の制度化**（本人×支援機関、本人×企業、支援機関×企業の各ペア）
- **不調のサインを共有**：本人・家族・企業・支援機関が同じサインを把握しておく
- キャリアアップの機会と仕組み（評価基準の明確化、昇給・昇格の可能性）
- 生活全体のサポート（余暇支援、住まい、経済的基盤＝障害年金・社会保障制度）
- ピアサポートの活用：同じ障害・経験を持つ先輩が相談相手になる

**失敗を避けるポイント**
- **就職直後だけサポートが厚く、その後消える**という支援の波を作らない
- 状態が安定していても定期的なアセスメントを継続（状態は変化する）
- 高齢化・障害進行に伴う業務変更の準備を早めに行う
- 精神疾患の方の「考えがくるくる変化する」に対して、一貫した関係者が対応する

---

### Phase 5：危機介入・離職防止
**目的**：危機的状況でも就労継続の選択肢を維持する

**成功のポイント**
- **「まず辞めない・相談する」という文化の醸成**：難病・精神疾患では特に重要。診断時から繰り返し伝える
- 迅速に動ける緊急対応体制の整備（誰に連絡するかのフローを事前合意）
- 同一企業内での**業務変更・配置転換**を離職の代替手段として持つ
- 休職→復職の支援フロー（就労移行支援、リワーク等との連携）

**失敗を避けるポイント**
- 難病・精神障害の方が「誰にも相談せず自己判断で退職」するパターンが最多の失敗モード
- ハローワーク等に紹介後のフォローを途切れさせない（紹介したら終わりにしない）
- 本人の意欲を「人任せ」にしない。意欲を引き出すのが支援者の役割

## 3. 関係者間の弱みを補う連携パターン

| 弱みのある関係者 | 課題 | 補う関係者・手段 |
|----------------|------|----------------|
| 企業（障害知識不足） | 合理的配慮の範囲が分からない | ジョブコーチ・就労移行支援事業所が具体的に教示 |
| 企業（孤立）| 支援が企業任せになる | 定期的な職場訪問・面談（支援機関） |
| 本人（自己理解不足） | 強み・弱み・必要な配慮を言語化できない | 支援機関がアセスメントツールで整理 |
| 本人（SOS出せない） | 不調を誰にも言えず突然退職 | 定期面談の制度化 + 相談しやすい人間関係の構築 |
| 家族（過保護・諦め） | 「我が子には無理」で機会を狭める | 成功事例の共有、家族を含めた面談 |
| 医療機関（就労知識不足）| 就職相談にはつなげない | 難病相談センター・就労支援機関が医療側に情報提供 |
| ハローワーク（フォロー不足）| 就職後のフォローが手薄 | 就労移行支援・定着支援機関との役割分担を明確化 |
| 学校（情報引き継ぎ困難）| 卒業後に情報が途絶える | 卒業前から次の支援機関と「顔の見える関係」を作る |

---

## 4. 横断的な成功の原則

### 4-1. 「顔の見える関係」が連携の基盤
全ワークショップで共通して強調されたのは、制度や手続きではなく**人と人の信頼関係**。
- 定期的な担当者会議・情報交流会を継続する
- 飲み会・見学・合同研修など、業務外の接点も有効

### 4-2. 情報を「つないだら終わり」にしない
- 「リファー後のフォロー」が最大の盲点。紹介した機関が継続的に状況を確認する
- フェイスシート・支援ポイントシートを関係機関で共有し、誰でも状況を把握できる仕組み

### 4-3. 本人の意欲・自己決定を中心に置く
- 支援者が「してあげる」ではなく、「本人が動く力を引き出す」姿勢
- ニーズは変化するため、一度聞いたら終わりではなく、定期的に確認し直す

### 4-4. 早期介入が最もコスパが高い
- 全フェーズを通じて、早いほど選択肢が多く、介入コストが低い
- 「就活直前」「離職直前」「退職後」ではなく、**その前の段階**で動く

### 4-5. 誰がコーディネーターか、常に明確にする
- 「誰が中核か？」が最大の課題として複数のワークショップで浮上
- 本人を中心に、医療・生活・就労の三領域を統合的に調整できる人材（または機関）を必ず決める

## 5. よくある失敗パターン（アンチパターン集）

| # | 失敗パターン | 発生しやすいフェーズ | 防止策 |
|---|------------|------------------|--------|
| 1 | 誰にも相談せず自己判断で退職 | Phase 4〜5 | 「まず相談」の文化醸成。相談先を診断時から明示 |
| 2 | ハローワーク紹介後にフォロー途絶 | Phase 3以降 | 紹介後の定期確認を役割として明記 |
| 3 | 企業だけに支援の重荷が集中 | Phase 3〜4 | 外部支援機関の定期訪問と三者連携 |
| 4 | 窓口が多すぎて本人が迷子 | Phase 2 | コーディネーター（一本化窓口）の設置 |
| 5 | 支援が就職時だけで長期フォロー消滅 | Phase 4 | 定着支援を仕組みとして制度化 |
| 6 | 画一的・機械的な支援 | 全フェーズ | 個別アセスメントを必ず実施 |
| 7 | 学校→社会の情報引き継ぎ断絶 | Phase 0〜1 | 卒業前から次機関と顔つなぎ |
| 8 | マッチング後のミスが放置 | Phase 3 | 試用期間中の集中的な三者面談 |
| 9 | 本人が「支援を求めることを知らない」 | 全フェーズ | 広報・周知・医療機関からの情報提供 |
| 10 | 家族が障害受容できず機会を塞ぐ | Phase 0〜1 | 家族を支援対象として巻き込む |

## 6. 難病・精神障害特有の追加ポイント

- **病状の波（寛解・増悪の繰り返し）**に合わせた柔軟な勤務形態（短時間・在宅・フレックス）
- 難病は「見えない障害」のため、企業・職場の理解形成が特に重要
- **「難病を言わずに就職→悪化→退職」**のパターンを防ぐため、開示のメリット・タイミングを本人と一緒に検討する
- 医療費負担が就労継続の障壁になりうる（制度活用の情報提供）
- **精神障害は手帳を持たない層**も多く、合理的配慮の適用が曖昧になりやすい
