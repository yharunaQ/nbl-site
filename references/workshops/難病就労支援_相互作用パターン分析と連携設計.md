## 1. 分析手法の設計

### 現在の整理方式の限界

元データの整理方式は「何が必要か」という**課題トピック別分類**（企業啓発・職業相談・連携等）である。これは支援メニューの目録としては有用だが、「誰が何に困って、どこで詰まって、何があれば解決するか」という**因果的・動態的な理解**には不十分。

### 第一原理からの分析方針

就労支援の問題は「複数の関係者が関わるシステム」の問題であり、個別の困りごとではなく**アクター間の相互作用の失敗パターン**として把握する。

**分析ステップ：**

1. 回答者IDから所属機関・立場を特定し「誰の視点か」を明確化
2. 同一回答者の複数発言を統合し、その人が見ている問題構造を理解
3. 複数の立場の回答者が「同じ場面の異なる側面」を語っているパターンを抽出
4. パターンを「何が先行条件で何がボトルネックか」という因果構造で記述
5. 各パターンにおける役割分担の現状と理想のギャップを特定

## 3. 相互作用パターン分析（7パターン）

### パターン1：「遅すぎる介入」スパイラル

#### 因果構造

```
難病診断
  ↓
就労情報が届かない（医療側からの情報提供なし）
  ↓
患者が一人で抱える
  ↓
病状悪化・退職
  ↓
生活困窮
  ↓
ようやく相談窓口へ（この時点で多重困難状態）
```

#### 各立場のエビデンス

| 立場 | 発言 |
|------|------|
| 難病相談センター [4110] | 「就労について来られる方は、すでに課題が大きくなっているパターンが多い」 |
| 保健師 [3155] | 「新規の相談で、すでに仕事を辞めてしまっていて、生活困窮している」 |
| 保健師 [3126] | 「PHNの引き出しには在宅ワークへつなぐことぐらいしかない」 |
| 医療 [4109] | 「将来の経済問題・就労問題を意識して早期から情報提供していきたい」 |

#### ボトルネック

> **診断〜就労問題顕在化の間の「就労支援の死角」。診断時に就労情報が渡らない。**

---

### パターン2：「縦割り抱え込み」ループ

#### 因果構造

```
患者が保健師・医療機関に就労相談
  ↓
就労支援スキルがない
  ↓
自機関で解決しようとする OR 何もできない
  ↓
就労支援機関につながらない
  ↓
解決しないまま問題が拡大
  ↓ （次の相談時には更に深刻化）
```

#### 各立場のエビデンス

| 立場 | 発言 |
|------|------|
| 保健師 [3201] | 「職場と医療機関をどのようにつないでいけばよいのかわからない。難しいと感じる」 |
| 保健師 [3228] | 「生活支援と医療の視点でサポートを続けられれば」（就労は範囲外という認識） |
| HW [1135] | 「難病患者については専門のサポーターが支援しているので詳しくわかりません」 |
| 患者会 [6102] | 「相談がたらい回しになっている。各機関が縦割りになっており支援につながらない」 |

#### ボトルネック

> **各機関が「自分の専門外」として回避するか抱え込むかの二択になっており、情報を持った「橋渡し」が機能していない。**

---

### パターン3：「難サポ一点集中・地理的空白」パターン

#### 因果構造

```
県に1名の難病患者就職サポーター（非常勤）
  ↓
HW内でサポーターに丸投げ
  ↓
物理的に県全体をカバー不能
  ↓
地方・遠隔地では実質機能しない
  ↓
地域全体の支援が難サポ個人の能力・所在地に依存
```

#### 各立場のエビデンス

| 立場 | 発言 |
|------|------|
| 保健師 [3253] | 「隣の市を拠点としているため、出張相談・訪問相談の対応はしていただけない状況」 |
| 保健師 [3116] | 「サポーターがいるが、県庁所在地にしかなく活用できない」 |
| HW [1128] | 「難病サポーター・HW・支援機関（ナカポツ）と取り組んでいる」（同一所在地でうまく機能しているケース） |
| HW [1155] | 「難病サポーターが配置されているため詳しくはまだわかりません」（丸投げ状態） |

#### ボトルネック

> **難サポは連携ハブになれる潜在力があるが、配置の希薄さと「丸投げ」がシステム全体のボトルネック。HW全体の難病支援力が育っていない。**

### パターン4：「企業-患者間コミュニケーション障壁」パターン

#### 因果構造（2分岐）

```
【ケースA：非開示ルート】
患者が難病を隠して就職
  → 配慮なし → 無理を続ける → 体調悪化 → 休職／退職
  （誰も介入できなかった）

【ケースB：開示ルート】
患者が開示を試みる
  → 企業の無理解・過剰反応 → 採用拒否・退職勧奨
  → 就労意欲の喪失
```

#### 各立場のエビデンス

| 立場 | 発言 |
|------|------|
| 保健師 [3224] | 「まだ自分の病気の受け入れができていない段階で職場へ相談ができず、黙っておきたいという人が多い」 |
| HW [1107] | 「非開示でもある程度は働けるが、職場での困りごとが出てくる」 |
| 患者 [6323] | 「入社時に伝えておいた方が本人・会社双方にとって良い」 |
| HW [1133] | 「事業主は最初重度というイメージを持っていたが、本人の人柄や配慮事項を直接話せたため採用を決めた」 |
| 難病相談 [6209] | 「認知の低い病気の場合、合理的配慮を得られる以前に門前払いを食らうケースが多い」 |

#### ボトルネック

> **開示のタイミング・方法の支援が不足。企業側の「難病＝働けない」という先入観が払拭されなければ、開示自体がリスクになる構造的問題。**

### パターン5：「制度の谷間による支援空白」パターン

#### 因果構造

```
障害者手帳なし（多くの難病患者）
  ↓
障害者雇用率の対象外
  ↓
企業に採用インセンティブなし
  ↓
就労支援機関でも積極的支援の根拠が弱い
  ↓
「一般求職者と同じ扱い」か「たらい回し」
  ↓
実質的に無支援
```

#### 各立場のエビデンス

| 立場 | 発言 |
|------|------|
| HW [1309] | 「谷間の難病のある人の就労・定着支援はハローワークの力の見せどころ」 |
| 患者本人 [5212] | 「手帳がないと支援してくれる機関がない」 |
| HW [1124] | 「障害者の相談窓口を利用しているが難病患者だからの＋αの支援は行っていない」 |
| 患者会 [8314] | 「難病と障害のはざまで苦しんでいる方がいるという発見があった」 |
| HW [1210] | 「社会として雇用していく責任を企業に果たさせる制度の法整備等が必要」 |

#### ボトルネック

> **制度設計上の構造問題。難病患者の就労支援の根拠が曖昧なため、各機関の積極的関与の動機が弱い。**

### パターン6：「医療情報と就労支援の断絶」パターン

#### 因果構造

```
【就労支援側からの困難】
患者が就労支援機関に相談
  → 病状・就労制限の医療情報がない
  → 適切な求人マッチング・配慮設定ができない
  → 不適切な就職 → 早期離職

【医療側からの困難】
患者が医療機関で就労相談
  → 主治医に就労可否判断の根拠・方法がない
  → 「就労は困難」か曖昧な回答
  → 支援が前進しない
```

#### 各立場のエビデンス

| 立場 | 発言 |
|------|------|
| HW [1115] | 「病院から情報提供があれば適切に対応できる」 |
| HW [1151] | 「難病の求職者・HW・医療機関でケース会議を行いたい。現在は意見書のみで判断」 |
| 医療 [4204] | 「診断時から就労について先を見越した支援に繋げたい。診療現場は忙しすぎて無理なので医療相談室に専門ナースが必要」 |
| 医療 [6112] | 「リハビリ職の強みとして作業を細分化して就労先に提示できる。MSWを通してHWとの連携も」 |

#### ボトルネック

> **医療機関と就労支援機関の間の「情報インターフェース」が制度化されていない。両立支援ガイドラインの仕組みが就職前段階には適用されにくい。**

---

### パターン7：「就職後フォロー空白による離職」パターン

#### 因果構造

```
就職成立（→支援終了とみなされる）
  ↓
フォロー体制なし
  ↓
進行性難病の病状変化・体調悪化への対応遅れ
  ↓
「もう限界」の段階でようやく相談
  ↓
既に職を失う寸前 or 離職済み
```
> 参考：難病患者は就職後10年以内に約半数が離職（調査結果）

#### 各立場のエビデンス

| 立場 | 発言 |
|------|------|
| 難病相談 [2019] | 「難病の人は就職しても10年ほどで半数離職。継続支援が大切」 |
| 難病相談 [2029] | 「継続支援の難しさ、関係性を保つ難しさ」 |
| 保健師 [3338] | 「就労していると訪問や電話がつながりにくく、支援に入りにくいのが課題」 |
| 就労支援 [7108] | 「進行していく病気の方の場合の継続支援が必要。一度の支援だけでなく継続の支援が患者にも企業側にも必要」 |
| 産業保健 [4104] | 「辞めてからの相談は介入にも時間がかかる」 |

#### ボトルネック

> **「就職＝支援終了」という慣行が難病には不適合。継続的なケアのための関係性維持と責任機関の設定が未整備。**

## 4. 典型的困難状況の構造的まとめ（3層構造）

### 第1層：患者レベルの困難

| 困難の種類 | 発生メカニズム | 対応するパターン |
|-----------|---------------|:---------------:|
| 診断後の情報なき漂流 | 医療側からの就労情報提供がなく、自ら動く前に退職 | P1 |
| 開示・非開示のジレンマ | 開示すれば差別リスク、非開示では配慮が得られない | P4 |
| 複合問題への単独対応 | 医療・生活・就労が絡み合う問題を自分で整理しなければならない | P2, P5 |
| 制度への不案内 | どこに相談すれば何が解決するかが不明瞭 | P2, P3 |

### 第2層：支援者・機関レベルの困難

| 困難の種類 | 発生メカニズム | 対応するパターン |
|-----------|---------------|:---------------:|
| 「つなぎ」技術の不足 | 自専門領域外のニーズを整理して適切な機関に送る能力が未育成 | P2 |
| 難病知識と就労支援知識の分断 | 保健医療側は就労を知らず、就労支援側は難病を知らない | P2, P6 |
| チーム支援体制の未整備 | HW・難病センター・医療の3者が個別に動き統合されない | P3, P6 |
| 難サポへの過度な依存 | 難病就労支援を一人の非常勤職員に集中させる構造 | P3 |

### 第3層：制度・システムレベルの困難

| 困難の種類 | 発生メカニズム | 対応するパターン |
|-----------|---------------|:---------------:|
| 法定雇用率対象外 | 企業が難病患者を雇用する社会的根拠が弱く採用インセンティブなし | P5 |
| 連携の業務手順・フロー未整備 | 誰が誰にいつつなぐかが決まらず属人的判断に依存 | P2, P3 |
| 就職後の継続支援の制度的空白 | 治療と仕事の両立支援が就職後の当事者に届かない | P7 |
| 地域格差 | 社会資源・支援機関の密度が地域によって大きく異なる | P3 |

## 5. 効果的な役割分担と連携のあり方（7ポイント）

### ポイント1：「早期介入」のゲートキーパー機能を医療・保健に組み込む

**核心：** 就労問題が深刻化する前に、診断直後・医療費助成申請時に介入できるかどうかが最大の分岐点。

| 機関 | 役割 |
|------|------|
| 医療機関・主治医 | 診断時の「仕事を辞めないで」メッセージ＋就労支援情報の提供 |
| 保健師・保健所 | 医療費助成申請・更新時の就労状況スクリーニング（簡易質問） |
| 難病相談支援センター | 上記窓口からの「つなぎ先」として機能する |

**現状のギャップ：** 医療・保健側は就労支援への「つなぎ方」を知らない／義務として位置付けていない。

---

### ポイント2：「つなぎ」を抱え込みでも丸投げでもなく「情報付き橋渡し」として機能させる

**核心：** 「つなぎ」は単なる紹介ではなく、患者の状況（医療情報・生活状況・就労ニーズ）を整理した情報共有を伴う能動的な協働。

| 機関 | 役割 |
|------|------|
| 保健師・MSW | 患者の「困りごとの言語化と整理」→適切な機関への情報付き紹介 |
| HW・難病サポーター | 紹介を受けた後の「就労支援のコア機能」の実施 |
| 難病相談支援センター | 複合問題の統合的アセスメントと関係機関間調整 |

**現状のギャップ：** 各機関が自分の専門範囲で閉じようとし「つなぎ」の質が低い（丸投げかゼロ紹介）。

---

### ポイント3：ハローワークの「難病対応の総合力」を難サポ依存から脱却させる

**核心：** 難サポへの丸投げをやめ、HW全体の難病対応力を底上げする。難サポはコーディネーターとして機能させ、直接支援はHW全体で行う。

| 機関・職種 | 役割 |
|-----------|------|
| 難病患者就職サポーター | チーム支援の核・地域関係機関との連携コーディネーター・地方への出張相談 |
| HW一般相談員 | 難病患者も含めた一般求人・障害者求人双方の職業相談 |
| 障害者職業センター | 職業評価・職業準備支援の専門機関として連携 |

**現状のギャップ：** 難サポへの過度な集中により、HW全体の難病支援力が育っていない。

---

### ポイント4：企業への働きかけは「難病採用のお願い」ではなく「具体的な個別支援情報の提供」で

**核心：** 「難病患者を雇ってください」という啓発では限界。「この方の病状・配慮ニーズ・強みはこうです」という個別情報提供こそが採用につながる。

| 機関・職種 | 役割 |
|-----------|------|
| HW・難病サポーター | 個別ケースに応じた求人開拓・事業所への直接説明 |
| 医療機関 | 「取扱説明書」的な就労配慮情報の提供（主治医意見書の活用） |
| 難病相談センター・就労支援機関 | 企業向け啓発セミナー・ナビゲーションブック作成支援 |

**現状のギャップ：** 啓発が一般論にとどまり、企業の「具体的にどう配慮すれば？」という疑問に答えられていない。

---

### ポイント5：「就職後の継続支援」を支援の終点ではなく中点として設計する

**核心：** 難病の就労支援は就職後10年以上のスパンで必要。就職直後だけでなく、病状変化のタイミングでの予防的介入が離職防止の鍵。

| 機関・職種 | 役割 |
|-----------|------|
| 産業医・産業保健総合センター | 在職中の治療と仕事の両立支援プランの策定・維持 |
| 主治医 | 病状変化の就労への影響の医学的評価と情報提供 |
| 保健所 | 医療費助成更新時の就業継続状況確認・定期フォロー |
| ナカポツ・就労支援機関 | 定期的な職場訪問と本人・企業双方へのフォローアップ |

**現状のギャップ：** 就職で「支援終了」になる傾向があり、就職後フォロー体制が設計されていない。

---

### ポイント6：地域の「難病就労支援ネットワーク」の連携フロー・業務手順を明文化する

**核心：** 属人的な「顔の見える関係」だけに依存した連携は持続しない。「誰が誰にいつどんな情報をどのように渡すか」を業務手順として明確化することが必要。

**具体的仕組み：**
- 難病対策地域協議会にHWが参加し、就労支援サブグループを設置
- 「難病就労支援フローチャート」の地域版を作成・全関係機関に共有
- 各機関の役割・対象・できることの一覧表を整備・周知

---

### ポイント7：ケースマネジメント機能を担う機関・役割を明確に設定する

**核心：** 難病患者の支援は医療・生活・就労が複合しており、全体を把握してコーディネートする「ケースマネジャー的機能」が不可欠。

**最も適した担い手（現状分析から）：**
- **難病相談支援センター**：医療・生活・就労をつなぐ位置にあり最も素地がある
- **難病患者就職サポーター**：ケースマネジメントの核になれるが配置が希薄

**制度的補完として必要なこと：**
- ケースマネジャー機能を担う機関・職種の公式な位置付け
- 関係機関の定期的なケアカンファレンスの制度化
- 介護保険のケアマネジャーに相当する難病就労支援コーディネーション機能の整備

## 7. 研修プログラム設計

### 7-1. 研修の設計原則

1. **立場別ではなく、「接点場面」別に設計する**  
   各機関が「自分の専門内」の研修だけを受けても連携は生まれない。「医療から就労へのつなぎ場面」など接点場面を軸にした合同研修が有効。

2. **知識習得だけでなく「相互理解と実践演習」を組み込む**  
   他機関が「何ができて何ができないか」を体験的に理解することが、実際の連携行動につながる。

3. **基礎・実践・応用の3段階で設計する**  
   新任者〜経験者まで対応できるよう段階を設け、各段階で必要なスキルを明確化する。

### 7-5. Level 3：連携実践研修（合同・事例検討）

**対象：** 地域連携に主体的に関わる実務者（保健師・HW難病サポーター・難病相談センター等）  
**形式：** 合同ワークショップ（1日 or 半日×複数回）  
**目標：** 地域内の関係機関が互いの役割を理解し、実際の連携を機能させる

#### プログラム（半日版・3.5時間）

```
09:00  ウォームアップ
       ─ 参加者自己紹介：「私の機関でできること・できないこと」
       ─ 互いの機関への質問出し合い（ポストイット）

09:30  地域の連携フローの共同作成
       ─ 現状の「誰が何をしているか」の可視化（付箋ワーク）
       ─ 「どこに空白・重複があるか」の確認
       ─ 理想の連携フローの草案作成

11:00  事例検討（グループワーク）
       ─ 架空または匿名化された複合困難事例の提示
       ─ 各機関はこの事例で何ができるか・何を担当するか
       ─ チーム支援計画の発表・フィードバック

12:30  地域連携の課題と改善策の合意形成
       ─ 今日から変えられること（個人・機関レベル）
       ─ 制度的に変える必要があること（提言レベル）
       ─ 次回の連携会議の日程調整
```

|--------------|------|
| 研修直後 | 他機関の役割理解度・自機関の役割認識の明確度・「つなぎ」の具体的方法の習得度 |

| 1年後 | 患者の就労相談が早期に届く割合・就職後1年の職場定着率・チーム支援実施ケース数 |

## 8. 結論：解決の核心

### 困難の本質

難病就労問題が「医療の課題でも就労支援の課題でもなく、その境界を横断するシステム問題」であることに対して、制度・組織・人材がすべて縦割りで設計されているという**構造的矛盾**にある。

### 最も解決インパクトが高い介入点

7つのパターンの中で、**パターン1（遅すぎる介入）×パターン2（縦割り抱え込み）×パターン7（就職後フォロー空白）の三連鎖**が最も多くの離職・生活困窮を生み出している。

```
【解決の3本柱】

①  早期介入のトリガーを医療・保健に埋め込む
   （診断時・申請時の就労アセスメントの義務化）

②  情報を持ちながら連携する「つなぎ」技術を各機関に付与する
   （丸投げでも抱え込みでもない情報付き橋渡し）

③  就職後も途切れない継続的ケアを担う
   ケースマネジャー機能を制度化する
   （難病就労支援コーディネーターの公式化）
```

この3点が揃うことで、7つのパターンのほとんどに同時対処できる。

### 短期・中期・長期のアクションプラン

| 時期 | アクション | 主担当 |
|------|-----------|--------|
| **短期**（〜1年） | 地域版連携フローチャートの作成 | 難病対策地域協議会 |
| **短期** | 難病就労支援研修の実施（Level 1・2） | 都道府県・障害者職業センター |
| **短期** | 医療費助成申請時の就労スクリーニング開始 | 保健所 |
| **中期**（1〜3年） | ハローワークを含む実務連携会議の定例化 | HW・難病相談センター |
| **中期** | 医療機関への「就労支援情報提供ツール」の整備・配備 | 難病相談センター・行政 |
| **中期** | 就職後フォロー体制の標準設計・試行 | HW・ナカポツ・産業保健センター |
| **長期**（3年〜） | 難病就労支援コーディネーター機能の制度的位置付け | 国・都道府県 |
| **長期** | 難病患者の法定雇用率算入等の制度整備 | 国・厚生労働省 |
