# フィードバックノート

配慮設計アシストの利用者から得たフィードバックをFounderが自由テキストで書き留めるディレクトリ。

## 書き方

ファイル名: `YYYY-MM-DD.md`（同日に複数書く場合は `YYYY-MM-DD-2.md` など）

フォーマットは自由。以下は一例：

```
# 2026-03-25

## フィードバック元
就労移行支援員 / メール

## 内容
p-fatigue-pacing の「問題は体力不足ではなく〜」という見立てが出たが、
この人の職場では業務の繁閑差が大きく、ペース管理より繁忙期の総量制限の方が
現実的だった。優先度の提示順が実態と合っていない印象。

p-manager-checkin は刺さった。相談ルートが整備されていなかったのが
まさに問題で、具体的な設計案が職場に渡せた。
```

## 分析スクリプト

```bash
npm run jac:feedback:analyze
```

`references/jac/feedback-insights.json` に構造化された洞察が出力される。
新しいフィードバックファイルだけを差分処理する。

## 出力の使い方

`feedback-insights.json` の `frameInsights` にフレームごとの傾向が蓄積される。
`suggestedRevision` は参考案であり、フレームデータへの反映はFounderが判断する。
