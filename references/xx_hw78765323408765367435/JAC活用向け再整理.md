# JAC活用向け再整理: ハローワーク障害者雇用支援ノウハウの普遍化

更新日: 2026-03-07

## 目的

- 日本の公共職業安定所（ハローワーク）が蓄積した障害者雇用支援の実践事例を、JACでも使える普遍的な支援ノウハウへ変換する。
- 変換方針は、「JACがすべてを内製する」のではなく、「JACが実装の骨格を持ち、地域の専門機関・専門支援者が専門性と継続支援を担う」とする。
- 日本固有の制度名や組織名は、そのまま移植するのではなく、機能単位へ翻訳して扱う。
- 注: `knowledge:catalog` / `knowledge:normalize` は、`README.md` を除く `.md` も取り込める前提で、この文書自体を知識入力の正本とする。

## JACでの提示原則

- 企業単独では実施負担が高い配慮や支援を提示する場合は、配慮案だけでなく、それを支える地域支援体制をセットで示す。
- 企業への提案は「何を配慮するか」に加えて、「誰が支えるか」「どこまで外部支援を使えるか」「困った時に誰へ戻せるか」まで含めて初めて実装しやすくなる。
- これにより、企業側の負担感を下げるだけでなく、配慮の実施可能性と継続可能性を上げやすい。

## Holistic Positioning

- Scope of source:
  - 元資料は [index/index.htm](index/index.htm) を入口とするハローワーク事例集であり、文中に平成18年度・平成19年度の記載があるため、主に2006年から2007年頃の日本の実践が含まれる。
  - 強いのは「現場で何をしたか」の事例知であり、最新制度や全国一律の標準手順を示す資料ではない。
- Covered lenses:
  - `difficulty_occurrence`: 就職活動、面接、実習、定着でどこに詰まりが起こるかが多く示されている。
  - `difficulty_resolution`: ケース会議、役割分担、ジョブコーチ、医療連携など、解決に必要な支援条件が示されている。
  - `symptom_work_interaction`: 精神障害、てんかん、生活面課題など、体調や生活条件が就労に影響する記述がある。
  - `support_need_formation`: 本人、家族、学校、事業所、支援機関の関係で必要支援が形づくられる様子が分かる。
- Missing lenses:
  - 当事者本人の主観や拒否感の記述は限定的である。
  - 定量的な長期追跡は薄い。
  - 現在の制度更新は含まれない。

## 元資料の性質の切り分け

- `observation`:
  - ジョブガイダンス、ケース会議、企業見学、実習、トライアル雇用、定着訪問、地域会議などの実践例が多数記録されている。
- `inference`:
  - 支援がうまくいく条件は、障害名そのものより、役割分担、情報共有、段階的支援、生活面との接続、企業側の理解形成にある。
- `normative`:
  - 支援は「紹介して終わり」ではなく、「見立て、試行、定着、再調整」を通した継続支援として組むべきである。
- `recommendation`:
  - JACでは、元資料を「地域専門支援者と協働して実装する就業支援オーケストレーションの知見」として使うのが安全である。

## What is currently usable

- Usable now:
  - 支援アクセスを低くする工夫
  - 個別支援計画とケース会議
  - 企業側のアセスメントと理解形成
  - 見学、実習、トライアルを挟んだ段階的マッチング
  - 定着支援と生活支援の接続
  - 地域会議や小規模チームによる役割分担
- Not yet usable:
  - 当時の制度名称や助成制度を、そのまま現在の標準として扱うこと
  - 診断名だけで支援内容を決めること
  - 成功事例を一般法則として断定すること

## 普遍的ノウハウへの再整理

### 1. 支援アクセスは「窓口案内」ではなく「到達支援」として設計する

- 元資料の観察:
  - 就職活動ガイダンス、面接練習、見学会、地域拠点での相談会、来所困難者への郵送対応が行われている。
  - 参照例:
    - [main/1076.htm](main/1076.htm)
    - [main/2605.htm](main/2605.htm)
    - [main/2612.htm](main/2612.htm)
    - [main/1034.htm](main/1034.htm)
    - [main/1008.htm](main/1008.htm)
- 普遍化した解釈:
  - 障害者雇用支援では、「相談に来る前」の障壁が大きい。
  - 入口での不安軽減、情報の具体化、相談しやすい時間や場所の設計自体が支援の一部である。
- JACでの具体化:
  - 支援導線を1枚で見せる。
  - 初回相談前に、見学、体験、質問会のような低負荷接点を用意する。
  - 来所前提にせず、オンライン、地域拠点、同行、資料送付の代替手段を持つ。
- 地域専門支援者が支える部分:
  - 地域の福祉施設、医療機関、相談支援事業所が「最初の接点」になる。
  - 地域支援者が同席、同行、事前情報整理を担うと、JACは初回から具体支援に入りやすい。
- 再評価トリガー:
  - 初回相談につながらない。
  - 情報が伝わっても行動に移れない。
  - 本人より先に家族や支援者の不安が強い。

### 2. 見立ては「障害名」ではなく「本人 × 仕事 × 環境 × 支援」の共同仮説でつくる

- 元資料の観察:
  - 支援計画への署名、四者面談、本人同意の上での情報共有、役割分担を前提にしたケース会議が成果につながっている。
  - 参照例:
    - [main/2627.htm](main/2627.htm)
    - [main/2684.htm](main/2684.htm)
    - [main/2614.htm](main/2614.htm)
    - [main/2615.htm](main/2615.htm)
- 普遍化した解釈:
  - うまくいく支援は、診断名を起点にするのではなく、本人の強み、仕事要求、職場環境、既存支援を組み合わせて仮説化している。
  - 合意された役割分担があると、支援が途切れにくい。
- JACでの具体化:
  - 支援計画テンプレートを、`person / job / environment / support / time` の5欄で持つ。
  - 初回から「誰が何を持ち帰るか」を決める。
  - 本人が同意する情報共有範囲を明示する。
- 地域専門支援者が支える部分:
  - 学校、就労移行支援、医療、生活支援は、JAC単独では見えにくい日常条件を持っている。
  - JACは見立てのハブになり、地域支援者は条件情報の厚みを担う。
- 再評価トリガー:
  - 支援者同士で本人理解が食い違う。
  - 面接や実習で想定外のつまずきが出る。
  - 家族、学校、医療の見立てと就労場面がつながらない。

### 3. 企業支援は「説得」ではなく「職務設計と受け入れ条件の具体化」として行う

- 元資料の観察:
  - 企業訪問や企業連絡会で、障害理解だけでなく、業務内容、受け入れ条件、実習可能性、助成制度を具体的に擦り合わせている。
  - 企業と同じ場に入り、同じ目線で関係を作る取組が有効とされている。
  - 参照例:
    - [main/2658.htm](main/2658.htm)
    - [main/2611.htm](main/2611.htm)
    - [main/2819.htm](main/2819.htm)
    - [main/1329.htm](main/1329.htm)
- 普遍化した解釈:
  - 企業側の不安は「障害理解不足」だけではなく、「どの仕事なら成り立つか」「誰が初期対応するか」「トラブル時に誰を呼ぶか」が不明な点にある。
  - 支援は啓発だけでなく、受け入れ設計の具体化まで含めて初めて実装しやすくなる。
- JACでの具体化:
  - 企業向けに、職務分解、必要配慮、初期フォロー体制、相談先を一体で整理する。
  - 企業の「採用可否」より先に、「どの条件なら成り立つか」を確認する。
  - 企業側にも小さな試行機会を用意する。
  - 企業単独では重い配慮は、地域支援者の伴走、職場適応支援、生活面フォローを含めた実施体制とセットで示す。
- 地域専門支援者が支える部分:
  - ジョブコーチ、就労支援機関、地域の雇用支援担当が職場実地の翻訳役を担う。
  - 地域支援者が企業事情を補足すると、JACの提案が一般論で終わりにくい。
- 再評価トリガー:
  - 企業が「配慮はしたいが何をすればよいか分からない」と止まる。
  - 採用前後で企業側の理解が急に浅くなる。
  - 配慮事項が本人説明頼みになっている。

### 4. マッチングは「紹介一回」ではなく「見学 → 実習 → 試行 → 採用」の段階設計にする

- 元資料の観察:
  - 実習前から雇用後まで節目ごとに会議を入れる、訓練結果を見てトライアル移行を判断する、保護者同伴見学で安心感を作るといった段階設計が繰り返し現れる。
  - 参照例:
    - [main/2678.htm](main/2678.htm)
    - [main/2633.htm](main/2633.htm)
    - [main/2700.htm](main/2700.htm)
    - [main/2841.htm](main/2841.htm)
    - [main/2800.htm](main/2800.htm)
- 普遍化した解釈:
  - マッチングの失敗は、能力不足より「条件が見えないまま本番に入ること」で起こりやすい。
  - 見学、実習、トライアルは、採用前のふるいではなく、双方の条件を可視化する工程として使うと効果が高い。
- JACでの具体化:
  - 採用前支援を「情報提供」「見学」「短期実践」「試行雇用」の階段に分ける。
  - 各段階で、次へ進む条件と、止める条件を明文化する。
  - 小規模チームで動き、支援者が増えすぎて責任がぼやけるのを避ける。
- 地域専門支援者が支える部分:
  - 実習設計、同行支援、職場適応支援、保護者支援、医療面の留意点確認などは、地域支援者の現場力が要る。
  - JACは判断の枠組みと会議設計を持ち、現場伴走は地域側が担う構図が実装しやすい。
- 再評価トリガー:
  - 実習で課題が見えたのに共有されない。
  - 面接では良かったが実地で崩れる。
  - 支援者ごとに「採用へ進める条件」が違う。

### 5. 定着支援は「就職後の相談」ではなく「生活・体調・対人面を含む継続支援」にする

- 元資料の観察:
  - 就職後の職場訪問、休日相談、生活面の引き継ぎ、医療や生活支援センターとの役割分担が、定着支援の中心として扱われている。
  - 参照例:
    - [main/1061.htm](main/1061.htm)
    - [main/2643.htm](main/2643.htm)
    - [main/2648.htm](main/2648.htm)
    - [main/2876.htm](main/2876.htm)
    - [main/2760.htm](main/2760.htm)
- 普遍化した解釈:
  - 定着の成否は、仕事そのものより、生活、金銭、通院、対人不安、疲労蓄積への早期対応で決まることが多い。
  - 就職支援と生活支援が切れていると、就業継続が不安定になりやすい。
- JACでの具体化:
  - 定着支援の観察項目を、業務、対人、生活、体調、通勤、通院の6面で持つ。
  - 問題が大きくなる前に相談を上げる閾値を決める。
  - 企業向けにも、困った時の連絡順序を見える化する。
- 地域専門支援者が支える部分:
  - 生活支援センター、医療、就業支援ワーカー、ジョブコーチが、JACでは持ちにくい継続接触を担う。
  - JACは「何を観察するか」「いつエスカレーションするか」を整理し、地域側に引き継ぐ。
- 再評価トリガー:
  - 遅刻、疲労、欠勤、対人トラブルが連続する。
  - 本人が問題を言語化しにくい。
  - 企業側が保護者や支援者へ直接依存し始める。

### 6. 地域支援は「紹介先一覧」ではなく「役割分担されたチーム運用」としてつくる

- 元資料の観察:
  - 月例会議、地域ネットワーク、就労部会、就労サポーター制度、小規模コアチームなど、地域連携を継続運用する仕組みが成果の土台になっている。
  - 参照例:
    - [main/2667.htm](main/2667.htm)
    - [main/2692.htm](main/2692.htm)
    - [main/2651.htm](main/2651.htm)
    - [main/2658.htm](main/2658.htm)
- 普遍化した解釈:
  - 地域連携は「困った時に誰かを紹介する」だけでは弱い。
  - 継続会議、役割の境界、情報共有ルール、緊急時の連絡線があると、JACの提案が現場で実行されやすくなる。
- JACでの具体化:
  - 地域資源を、紹介先一覧ではなく機能マップで持つ。
  - ケースごとに、コア3機能から始める。
  - 会議の目的を「情報共有」だけで終わらせず、「次回までの担当」と「再評価条件」を残す。
- 地域専門支援者が支える部分:
  - 各機関の実務範囲、制度制約、地域事情を踏まえた実装調整を担う。
  - JACは地域チームの共通言語と進行役を担う。
- 再評価トリガー:
  - 連携先は多いが誰も主担当にならない。
  - 情報共有だけで次の行動が決まらない。
  - 本人が複数機関の間で説明を繰り返して疲弊している。

## JACと地域専門支援者の役割分担フレーム

| 実装フェーズ | JACが持つべき中核                                | 地域専門機関・専門支援者が持つべき中核       | 実施しやすくなる理由                          |
| ------------ | ------------------------------------------------ | -------------------------------------------- | --------------------------------------------- |
| 入口設計     | 支援導線の設計、初期見立ての視点提供             | 初回接点、同行、事前情報整理                 | JACが入口で詰まらず、初回から具体化しやすい。 |
| ケース把握   | person/job/environment/support/time の枠組み整理 | 日常情報、生活条件、医療情報、学校情報の補完 | 見立てが属性固定に流れにくい。                |
| 企業調整     | 職務設計と配慮整理の骨格提示                     | 企業訪問、職場理解、実地助言                 | 一般論ではなく現場条件に即した提案になる。    |
| 実習・試行   | 段階設計、会議進行、判断基準整理                 | 同行、実習支援、ジョブコーチ、保護者調整     | 条件確認が本番前に行える。                    |
| 定着支援     | 観察項目、再評価条件、連絡線の設計               | 継続接触、生活支援、体調フォロー、職場適応   | 早期警戒がしやすく、離職前対応がしやすい。    |
| 地域連携     | 共通言語、役割整理、会議設計                     | 地域事情に応じた実装、制度接続、専門判断     | JACの枠組みが地域で実行可能な形に落ちる。     |

## Bias / Discrimination Risk

- Risk level: `medium`
- Risk factors:
  - 成功事例集のため、うまくいかなかった条件が薄い。
  - 精神障害、知的障害などのラベルで始まる実践名があり、そのまま使うと診断名中心の理解に戻りやすい。
  - 日本の2006年から2007年頃の制度前提が混ざる。
- 安全に使う条件:
  - 支援提案は必ず条件付きで書く。
  - 制度や機関名は機能に翻訳して扱う。
  - 本人、仕事、環境、支援、時間の確認なしに処方箋化しない。

## Additional Information Required

- Must-have questions:
  - JACが直接担う範囲と、地域支援者に委ねる範囲はどこで切るか。
  - 想定している地域資源は、医療、生活、就労準備、ジョブコーチのどこまで揃っているか。
  - 対象は、求職者支援、企業支援、定着支援のどこが中心か。
- Nice-to-have questions:
  - 若年移行、高次脳機能、精神、難病など、優先したいケース群はあるか。
  - 地域会議を定例化できるのか、個別ケース時のみ招集するのか。

## Provisional Next Action

- Minimal safe action now:
  - JACでこの資料を使うときは、まず「地域支援機能マップ」を作る。
  - その上で、入口設計、共同見立て、企業調整、段階的マッチング、定着支援の5段階に分けて支援導線を組む。
  - 企業向けに配慮案を出す際は、必ず「企業内で担う部分」と「地域支援者が支える部分」を分けて提示する。
- Re-evaluation trigger:
  - 地域側に担当不在領域がある。
  - ケースが生活、医療、家族、企業の複合調整を要する。
  - 本人の希望より支援者都合が前面に出始める。
