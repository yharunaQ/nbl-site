認知補助ツールキット / Package 02

がんばり美談から、
仕事の前提へ。

「あの人は本当にすごい」で終わると、本人の努力が吸収している仕事の段差が見えなくなります。このキットは、称賛を入口にしながら、再現可能な仕事条件へ戻すための教材です。

使い方: 美談や善意を否定しません。そこに隠れた役割、情報、評価、相談線、余力を見つけ、次の二週間で変える前提を一つ選びます。

KIT MAP / このキットに入っているもの

6つの機能を、実物として使う。

注意 比喩 場面 構造 ワーク 読み下し

会議や研修では、まずマンガか音から入り、次に場面カード、最後に「がんばり前提分解シート」へ進みます。読み下しは、教材が本人責任論や職場批判へ滑らないように意味を守る部分です。

EXPERT READ / 専門チームの読み

努力は尊い。でも、努力だけで回る仕事は壊れやすい。

称賛で隠れるもの

成果、笑顔、献身の裏で、変更連絡、相談、引き継ぎ、例外対応を本人が吸収していることがある。

職場側の接触点

役割、評価、情報共有、人員余力、安全、顧客対応のどこに段差があるかを見る。

支援者の翻訳負荷

本人の強みや努力を、仕事条件の変更へ翻訳できないと、美談だけが残りやすい。

次の一手

「すごい人」を増やすのではなく、同じ成果を本人の消耗を減らして出せる条件を一つ変える。

OPEN / 注意を開く

入口カード: その称賛の裏で、何が吸収されているか。

止まりやすい見方

「本人がすごい」

よく頑張っている。周囲も助かっている。だから良い事例に見える。

Falconの読み

努力が埋めている前提を見る

変更連絡、暗黙ルール、相談役、評価の偏り、休憩の削りを、本人が引き受けていないか。

次の問い

同じ成果を、消耗を減らして出すには

誰が、いつ、何を共有すれば、本人だけが頑張り続けなくてよいか。

METAPHOR / 比喩でつかむ

ヒーローを増やすより、床を平らにする。

脱エイブリズムのマンガ

「すごい人を増やす」から、「すごくなくても続けられる仕事条件を作る」へ視点を移す。

画像を開く

音の入口: がんばりより設計

研修の冒頭やSNS短尺で、努力礼賛から仕事設計へ空気を変えるための入口。

短い合言葉: いい話で終わらせない。いい仕事条件へ戻す。

SCENE / 場面で見る

一日の中で、美談が生まれる場所を見る。

朝

誰より早く来て、昨日の変更連絡を整理している。

見る点: 変更情報は本人だけに集まっていないか。

昼

困っている同僚を助け、自分の休憩を削っている。

見る点: 支援役割が非公式に偏っていないか。

夕方

成果は出ているが、本人だけが疲れ切っている。

見る点: 評価が成果だけを拾い、持続可能性を見ているか。

会議

「頼りになる人」と評価されるが、仕事条件は変わらない。

見る点: 称賛が改善の代わりになっていないか。

STRUCTURE / 構造に置く

称賛を、仕事条件の表へ分解する。

よくある称賛
隠れている前提
変えられる仕事条件
「いつも先回りしてくれる」
変更情報、期限、完成形が本人の頭の中に集まっている。
変更連絡の置き場、確認時刻、完成形サンプルを共有する。
「困っている人を放っておかない」
相談役が非公式に偏り、本人の休憩や本来業務が削られる。
相談当番、一次受けの範囲、引き継ぎ先を決める。
「休まず安定している」
体調、通院、回復時間が評価や予定に乗っていない。
繁忙期、休憩、回復時間、代替手順を予定に入れる。

READ-DOWN / 読み下しで守る

頑張りを否定せず、頑張りだけに閉じない。

このキットは、努力している本人を責めるものでも、職場を責めるものでもありません。努力で埋めていた条件を見える形にし、本人の消耗を減らしながら成果を出す仕事条件へ戻すための入口です。

称賛は、関係者の善意を開く力があります。ただし、そこで止まると、同じ働き方を他の人に移植できず、本人の負担も減りません。美談を、役割、情報、相談線、評価、余力へ置き直すことで、現場で試せる改善になります。

扱わないこと: 個別の評価、雇用判断、法的判断、合理的配慮の妥当性判断。この教材は、会議や研修で同じ場面を見るための認知補助です。
