# JAC Guidebook Files

Place paid ebook files in this directory (example: `jac-guidebook.pdf`).

Default runtime lookup:

- file path: `public/ebooks/jac-guidebook.pdf`
- download filename: `jac-guidebook.pdf`

You can override these with environment variables:

- `JAC_GUIDEBOOK_FILE_PATH`
- `JAC_GUIDEBOOK_FILE_NAME`
